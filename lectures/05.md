## 5.1 多次加密下的不可区分性

### 5.1.1 从一条密文到多条密文 <Src p="5" />

上一讲的窃听实验 $\mathsf{PrivK}^{\mathsf{eav}}_{\mathcal{A},\Pi}$ 中，敌手**只能观察一条密文**。可现实里同一把密钥会被反复使用——如果敌手能看到**用同一密钥加密的多条密文**呢？我们用一个新实验 $\mathsf{PrivK}^{\mathsf{mult}}_{\mathcal{A},\Pi}$ 来刻画这种情形。

::: def 多消息窃听实验 $\mathsf{PrivK}^{\mathsf{mult}}_{\mathcal{A},\Pi}(n)$ @P6
1. 给定安全参数 $n$，敌手 $\mathcal{A}$ 输出一对**等长的消息列表** $\vec M_0=(m_{0,1},\dots,m_{0,t})$ 与 $\vec M_1=(m_{1,1},\dots,m_{1,t})$，其中对所有 $i$ 有 $|m_{0,i}|=|m_{1,i}|$，发送给挑战者 $\mathcal{C}$；
2. $\mathcal{C}$ 运行 $\mathsf{Gen}(1^n)$ 得到密钥 $k$，选取均匀比特 $b\in\{0,1\}$，对所有 $i$ 计算 $c_i\leftarrow\mathsf{Enc}_k(m_{b,i})$，把 $\vec C=(c_1,\dots,c_t)$ 发给 $\mathcal{A}$；
3. $\mathcal{A}$ 输出一个比特 $b'$；
4. 若 $b'=b$，实验输出 1，否则输出 0。
:::

::: def 窃听者存在时的多次加密不可区分 Indistinguishable multiple encryptions（定义 3.19） @P7
私钥加密方案 $\Pi=(\mathsf{Gen},\mathsf{Enc},\mathsf{Dec})$ 在窃听者存在时具有**多次加密不可区分性**，如果对所有 PPT 敌手 $\mathcal{A}$，存在可忽略函数 $\mathsf{negl}$ 使得

$$\Pr\big[\mathsf{PrivK}^{\mathsf{mult}}_{\mathcal{A},\Pi}(n)=1\big]\le\frac12+\mathsf{negl}(n),$$

其中概率取自 $\mathcal{A}$ 的随机性与实验中的随机性。
:::

::: ex [补充说明] 与单条密文的定义比较
取 $t=1$，$\mathsf{PrivK}^{\mathsf{mult}}$ 就退化为 $\mathsf{PrivK}^{\mathsf{eav}}$。所以“多次加密不可区分”**蕴含**“（单次）不可区分”；下面的例子说明反过来不成立。
:::

### 5.1.2 单次不可区分 ≠ 多次不可区分 <Src p="8" />

考虑上一讲用 PRG 构造的、具有不可区分加密的方案：用密钥 $k$ 经 PRG 生成 pad，再与明文异或，$\mathsf{Enc}_k(m)=G(k)\oplus m$。

<Fig src="/img/05/p008.jpg" size="sm" cap="图 1：一个具有不可区分加密的方案（密钥 → PRG → pad → 与明文异或）" p="8" />

::: qa 设 PRG 生成 3 位的伪随机 pad。敌手能区分 “cat, cat” 的密文与 “cat, dog” 的密文吗？ @P8
**能。** 敌手提交 $\vec M_0=(\text{cat},\text{cat})$、$\vec M_1=(\text{cat},\text{dog})$。两条消息用的是**同一个** pad $G(k)$，于是 $c_1=c_2 \iff m_{b,1}=m_{b,2}$。敌手规则：$c_1=c_2$ 则输出 $b'=0$，否则输出 $b'=1$——**以概率 1 获胜**。

**教训：需要概率加密（Probabilistic encryption）。**

<span class="muted">注：课件说 “3 位的 pad”，而 “cat” 编码后显然不止 3 位；理解为“pad 与消息等长”即可，不影响结论。</span>
:::

<L05MultiEncAttack />

::: prin [补充说明] 确定性加密不可能多次加密安全
若 $\Pi$ 的 $\mathsf{Enc}$ 是**确定性**的（且无状态），则 $\Pi$ 不可能具有多次加密不可区分性。

**证明**：构造敌手 $\mathcal{A}$：输出 $\vec M_0=(m,m)$、$\vec M_1=(m,m')$，其中 $m\neq m'$ 且等长；收到 $(c_1,c_2)$ 后，若 $c_1=c_2$ 输出 $0$，否则输出 $1$。

- $b=0$ 时：$c_1=\mathsf{Enc}_k(m)=c_2$（确定性 ⇒ 同一输入同一输出），$\mathcal{A}$ 必输出 $0$，猜对；
- $b=1$ 时：$c_1=\mathsf{Enc}_k(m)$，$c_2=\mathsf{Enc}_k(m')$。由解密正确性，$\mathsf{Dec}_k(c_1)=m\neq m'=\mathsf{Dec}_k(c_2)$，故 $c_1\neq c_2$，$\mathcal{A}$ 必输出 $1$，猜对。

所以 $\Pr[\mathsf{PrivK}^{\mathsf{mult}}_{\mathcal{A},\Pi}(n)=1]=1$，远大于 $\tfrac12+\mathsf{negl}(n)$。∎ 要想多次加密安全，**同一明文每次加密都必须（以高概率）得到不同的密文**。
:::

::: tldr
多条密文会暴露“哪些明文相同”；确定性加密在 $\mathsf{PrivK}^{\mathsf{mult}}$ 中必败——必须用**概率加密**。
:::

## 5.2 CPA 安全

### 5.2.1 什么是选择明文攻击 <Src p="10" />

进行**选择明文攻击**（<span class="en">Chosen-Plaintext Attack, CPA</span>）的敌手可以（部分地）**控制诚实参与方加密什么**。选择明文攻击**涵盖**了已知明文攻击（能自己挑明文，当然也就能“知道”明文/密文对）。

::: ex [补充说明] 现实中的 CPA
第 01 讲提到的中途岛战役：美军故意用明文发出“中途岛淡水设备故障”的假消息，诱使日军加密并发送含 “AF” 的电报，从而确认 AF 就是中途岛。在形式化定义里，这种能力被抽象为**加密预言机** $\mathsf{Enc}_k(\cdot)$：敌手随时可以提交任意 $m$，得到 $\mathsf{Enc}_k(m)$。
:::

### 5.2.2 CPA 不可区分实验

::: def CPA 不可区分实验 $\mathsf{PrivK}^{\mathsf{cpa}}_{\mathcal{A},\Pi}(n)$ @P11
1. 运行 $\mathsf{Gen}(1^n)$ 生成密钥 $k$；
2. 敌手 $\mathcal{A}$ 得到输入 $1^n$ 和对 $\mathsf{Enc}_k(\cdot)$ 的**预言机访问**，输出一对**等长**消息 $m_0,m_1$；
3. 选取均匀比特 $b\in\{0,1\}$，计算挑战密文 $c\leftarrow\mathsf{Enc}_k(m_b)$ 交给 $\mathcal{A}$；
4. $\mathcal{A}$ **继续拥有**对 $\mathsf{Enc}_k(\cdot)$ 的预言机访问，最后输出比特 $b'$；
5. 若 $b'=b$，实验输出 1（称 $\mathcal{A}$ **成功**），否则输出 0。
:::

::: def CPA 安全（定义 3.22） @P12
私钥加密方案 $\Pi=(\mathsf{Gen},\mathsf{Enc},\mathsf{Dec})$ 具有**选择明文攻击下的不可区分加密**，即 **CPA 安全**（<span class="en">CPA-secure</span>），如果对所有 PPT 敌手 $\mathcal{A}$，存在可忽略函数 $\mathsf{negl}$ 使得

$$\Pr\big[\mathsf{PrivK}^{\mathsf{cpa}}_{\mathcal{A},\Pi}(n)=1\big]\le\frac12+\mathsf{negl}(n),$$

其中概率取自 $\mathcal{A}$ 的随机性以及实验中的随机性。
:::

<span class="muted">（课件 P12 公式里漏写了 $(n)$，即 $\Pr[\mathsf{PrivK}^{\mathsf{cpa}}_{\mathcal{A},\Pi}=1]$，按上式理解。）</span>

<L05CpaGame />

::: qa 敌手手里有加密预言机，他把 $m_0$ 交给预言机加密，再和挑战密文比一比——这不就赢了吗？为什么还可能存在 CPA 安全的方案？ @P12
对**确定性**方案，这招确实必胜：$\mathsf{Enc}_k(m_0)$ 与挑战密文相同当且仅当 $b=0$。所以 **CPA 安全的方案必须是随机化的**：同一个 $m_0$ 每次加密结果都不同，预言机给出的 $\mathsf{Enc}_k(m_0)$ 与挑战密文“对不上”，比较不出任何东西。下一部分会用**伪随机函数**构造这样的方案。
:::

::: ex [补充说明] CPA 安全的几个直接推论
- **CPA 安全 ⇒ 窃听者下不可区分**：$\mathsf{PrivK}^{\mathsf{eav}}$ 敌手就是一个从不调用预言机的 CPA 敌手。
- **CPA 安全 ⇒ 加密必须随机化**（见上面的 Q）。
- 5.6 节将看到：**CPA 安全 ⇒ 多次加密的 CPA 安全**，这是 CPA 定义的一大优势。
:::

::: exam [考点] 期中 Q6：证明某方案不是 CPA 安全的
2025 期中第 6 题要求：针对一个（CBC 变体的）方案**给出具体的 CPA 攻击**，并**计算该攻击在 $\mathsf{PrivK}^{\mathsf{cpa}}$ 中的确切获胜概率**。答题套路：① 说明敌手如何利用加密预言机（往往是“构造与挑战密文共享某部分输入的查询”）；② 写清敌手的判定规则；③ 用全概率公式按 $b=0/1$ 分情况算 $\Pr[b'=b]$，说明它与 $\tfrac12$ 的差不可忽略。
:::

::: tldr
CPA 安全 = 敌手全程可调用加密预言机，仍猜不出挑战密文加密的是 $m_0$ 还是 $m_1$。确定性方案一查即破。
:::

## 5.3 伪随机函数

### 5.3.1 PRF 是用来干什么的 <Src p="15" />

- 想要“看起来随机”的**串**，就用**伪随机生成器**（PRG）；
- 想要“看起来随机”的**函数**，就用**伪随机函数**（<span class="en">Pseudorandom Function, PRF</span>）。

### 5.3.2 函数与随机函数

先用 $\{0,1\}$ 上的函数来说明 <Src p="16" />：

<FigGrid>
<Fig src="/img/05/p016a.jpg" cap="图 2：{0,1} 上的一个函数（0↦1，1↦0）" p="16" />
<Fig src="/img/05/p016b.jpg" cap="图 3：Func₁，{0,1} 上所有函数的集合（共 4 个）" p="16" />
<Fig src="/img/05/p016c.jpg" cap="图 4：从 {0,1} 到 {0,1} 的随机函数——从 Func₁ 中以各 1/4 的概率均匀选一个" p="16" />
</FigGrid>

::: def 函数、$\mathsf{Func}_n$ 与随机函数 @P17
- **函数**是从 $\{0,1\}^{l_{in}}$ 到 $\{0,1\}^{l_{out}}$ 的映射；若 $l_{in}=l_{out}$，称它**保长**（<span class="en">length-preserving</span>）。
- 记 $\mathsf{Func}_n$ 为所有从 $\{0,1\}^n$ 到 $\{0,1\}^n$ 的函数构成的集合，其大小为

$$|\mathsf{Func}_n|=(2^n)^{2^n}=\underbrace{2^n\cdot 2^n\cdots 2^n}_{2^n\ \text{个}}=2^{n\cdot 2^n}.$$

- **（均匀）随机函数**是从 $\mathsf{Func}_n$ 中均匀随机选出的一个函数。
:::

::: ex [补充说明] 为什么是 $2^{n\cdot2^n}$？——以及“惰性采样”
一个函数由它的**函数表**唯一确定：$2^n$ 个输入，每个输入对应 $2^n$ 种可能输出，所以共 $(2^n)^{2^n}$ 个函数。$n=1$ 时为 $2^2=4$，正是图 3 的 4 个函数。

等价地，“均匀选一个随机函数 $f$”可以理解为：**对每个输入 $x$，独立均匀地选 $f(x)$**。这带来一个在证明中极其好用的视角——**惰性采样**（<span class="en">lazy sampling</span>）：不必事先写出整张 $n\cdot2^n$ 位的函数表，只在某个 $x$ **第一次**被查询时才均匀采样 $f(x)$ 并记入表中，再次查询时查表返回。两种方式下敌手看到的分布完全相同。下面的 PRF 区分游戏中，打开“上帝视角”就能看到这张表。
:::

### 5.3.3 带密钥函数与伪随机函数 <Src p="18" />

::: def 带密钥函数 Keyed function @P18
- **带密钥函数** $F:\{0,1\}^{l_{key}}\times\{0,1\}^{l_{in}}\to\{0,1\}^{l_{out}}$ 是一个两输入函数，第一个输入称为**密钥**，记作 $k$。
- 本讲只考虑**保长**的情形：$l_{key}(n)=l_{in}(n)=l_{out}(n)=n$。
- 若存在多项式时间算法，给定 $k$ 和 $x$ 能算出 $F(k,x)$，称 $F$ 是**高效的**（<span class="en">efficient</span>）。
- 典型用法：选定并固定一个密钥 $k$，关心单输入函数 $F_k(x)\overset{\text{def}}{=}F(k,x)$。
- 若均匀随机地选 $k$，带密钥函数 $F$ 就在 $\mathsf{Func}_n$ 上诱导出一个自然的**分布**。
- 若（对均匀随机的 $k$）$F_k$ 与（均匀）随机函数**不可区分**，称 $F_k$ 是**伪随机的**。

<span class="muted">注：课件写作 $F_k:\{0,1\}^*\to\{0,1\}^*$，在保长设定下应为 $F_k:\{0,1\}^n\to\{0,1\}^n$；严格地说，“伪随机”是带密钥函数 $F$（这一族函数）的性质，而不是某个固定 $F_k$ 的性质。</span>
:::

::: qa $F_k$ 能不能“就是”一个随机函数？ @P18
不能。$k$ 只有 $2^n$ 种取值，所以 $\{F_k\}$ **最多**只是 $\mathsf{Func}_n$ 中的 $2^n$ 个函数，而 $|\mathsf{Func}_n|=2^{n\cdot2^n}$——绝大多数函数根本不可能被选中。PRF 的要求只是：**在多项式时间、只能黑盒查询的敌手眼中**，这 $2^n$ 个函数中随机挑一个，“看起来”和从全部 $2^{n\cdot 2^n}$ 个中随机挑一个一样。<span class="muted">（补充说明）</span>
:::

### 5.3.4 形式化定义

::: def 伪随机函数（定义 3.25） @P19
设 $F:\{0,1\}^{l_{key}(n)}\times\{0,1\}^{l_{in}(n)}\to\{0,1\}^{l_{out}(n)}$ 是高效的保长带密钥函数（$l_{key}(n)=l_{in}(n)=l_{out}(n)=n$），$f$ 是从 $\mathsf{Func}_n$ 中均匀选取的随机函数。若对所有 PPT 区分器 $D$，存在可忽略函数 $\mathsf{negl}$ 使得

$$\Big|\Pr\big[D^{F_k(\cdot)}(1^n)=1\big]-\Pr\big[D^{f(\cdot)}(1^n)=1\big]\Big|\le\mathsf{negl}(n),$$

则称 $F$ 是**伪随机函数**。其中 $\mathsf{Func}_n$ 是所有把 $n$ 位串映射到 $n$ 位串的函数之集；第一个概率取自 $k\in\{0,1\}^n$ 的均匀选取和 $D$ 的随机性，第二个概率取自 $f\in\mathsf{Func}_n$ 的均匀选取和 $D$ 的随机性。
:::

::: warn [要点] 读定义时容易忽略的三件事
1. $D^{\mathcal{O}(\cdot)}$ 表示 $D$ 对 $\mathcal{O}$ 有**预言机访问**：只能提交 $x$、拿回 $\mathcal{O}(x)$，**看不到密钥 $k$**。若把 $k$ 给 $D$，$D$ 只需自己算一下 $F_k(x)$ 与预言机答案比较，任何 $F$ 都会被区分。
2. $D$ 是 PPT 的，所以**只能查询多项式个点**；它不可能把 $2^n$ 个点的函数表全部查一遍。
3. 和 PRG 不同：PRG 的区分器拿到的是**一个串**；PRF 的区分器可以**自适应地**选择查询点（根据前面的答案决定下一个问什么）。<span class="muted">（补充说明）</span>
:::

<L05PrfGame />

::: ex [补充说明] 反例：$F_k(x)=k\oplus x$ 不是 PRF
它高效、保长，而且对每个**单独**的 $x$，$F_k(x)$ 都是均匀的。但区分器 $D$：查询 $x_1=0^n$、$x_2=1^n$ 得到 $y_1,y_2$，若 $y_1\oplus y_2=x_1\oplus x_2=1^n$ 输出 1，否则输出 0。

- 预言机为 $F_k$：$y_1\oplus y_2=(k\oplus x_1)\oplus(k\oplus x_2)=x_1\oplus x_2$ 恒成立，$\Pr[D^{F_k}=1]=1$；
- 预言机为 $f$：$f(x_1),f(x_2)$ 是两个独立均匀的 $n$ 位串（$x_1\neq x_2$），$y_1\oplus y_2$ 均匀，$\Pr[D^{f}=1]=2^{-n}$。

优势 $1-2^{-n}$ 不可忽略。教训：**“每个输出单独看都均匀”远远不够，PRF 要求多个输出之间也像独立均匀的**。
:::

::: exam [考点] 期中 Q4 / Q5：判断与证明 PRF
**Q4（判断）**：已知 $F$ 是 PRF，$F'$ 是否一定是 PRF？
- $F'(k,x)=F(k,x)\,\|\,F(k,\bar x)$（$\bar x$ 为按位取反）：**不一定**。查询 $x$ 得 $a\|b$，再查询 $\bar x$ 必得 $b\|a$；真随机函数满足“前后半段对调”的概率只有 $2^{-n}$。（上面演示里的第三个选项）
- $F'(k,x)=F(k,G(x))$（$G$ 为 PRG）：**不一定**。PRG 只保证均匀输入下的输出伪随机，不保证无碰撞；可改造出在 $0^n$ 与 $1^n$ 上输出相同的 PRG $G'$，则查询 $0^n,1^n$ 必得相同输出。

**Q5（证明）**：已知 $F$ 是 PRF，证明 $F'(k,x)=F(k,x)\oplus x$ 也是 PRF。

**证明**（规约 / 反证法）：假设存在 PPT 区分器 $\mathcal{A}$ 与不可忽略函数 $\varepsilon$，使
$$\Big|\Pr[\mathcal{A}^{F'_k}(1^n)=1]-\Pr[\mathcal{A}^{f}(1^n)=1]\Big|=\varepsilon(n).$$
构造区分器 $\mathcal{B}^{\mathcal{O}}$：运行 $\mathcal{A}$；每当 $\mathcal{A}$ 查询 $x$，$\mathcal{B}$ 向自己的预言机查询得 $\mathcal{O}(x)$，回答 $\mathcal{O}(x)\oplus x$；最后输出 $\mathcal{A}$ 的输出。$\mathcal{B}$ 只比 $\mathcal{A}$ 多做多项式次异或，是 PPT 的。

- $\mathcal{O}=F_k$：$\mathcal{A}$ 收到的恰是 $F_k(x)\oplus x=F'_k(x)$，故 $\Pr[\mathcal{B}^{F_k}=1]=\Pr[\mathcal{A}^{F'_k}=1]$；
- $\mathcal{O}=f$：$\mathcal{A}$ 收到的是 $g(x)\overset{\text{def}}{=}f(x)\oplus x$。由于 $x\mapsto f(x)\oplus x$ 对每个 $x$ 都是把均匀的 $f(x)$ 平移一个固定值，且各 $x$ 之间独立，$g$ 也是 $\mathsf{Func}_n$ 上的均匀随机函数，故 $\Pr[\mathcal{B}^{f}=1]=\Pr[\mathcal{A}^{f}=1]$。

两式相减得 $|\Pr[\mathcal{B}^{F_k}=1]-\Pr[\mathcal{B}^{f}=1]|=\varepsilon(n)$ 不可忽略，与 $F$ 是 PRF 矛盾。∎

这一“**用 $\mathcal{A}$ 搭出 $\mathcal{B}$、分两个世界算概率**”的模板，正是 5.5 节定理 3.31 的证明骨架。
:::

::: tldr
PRF：随机密钥下的 $F_k$，在只能黑盒查询的 PPT 区分器看来与真随机函数无法区分。真随机函数可以“惰性采样”。
:::

## 5.4 构造 3.30

<Fig src="/img/05/p022.jpg" size="md" cap="图 5：用伪随机函数构造 CPA 安全加密——随机串 r 经 PRF 得到 pad，与明文异或；r 与异或结果一起组成密文" p="22" />

::: def 构造 3.30：由任意伪随机函数得到 CPA 安全方案 @P23
设 $F$ 是伪随机函数。为长度为 $n$ 的消息定义私钥加密方案：

- $\mathsf{Gen}$：输入 $1^n$，均匀选取 $k\in\{0,1\}^n$ 并输出；
- $\mathsf{Enc}$：输入密钥 $k\in\{0,1\}^n$ 与消息 $m\in\{0,1\}^n$，均匀选取 $r\in\{0,1\}^n$，输出密文
$$c:=\langle r,\ F_k(r)\oplus m\rangle;$$
- $\mathsf{Dec}$：输入密钥 $k\in\{0,1\}^n$ 与密文 $c=\langle r,s\rangle$，输出明文
$$m:=F_k(r)\oplus s.$$
:::

**正确性**：$\mathsf{Dec}_k(\mathsf{Enc}_k(m))=F_k(r)\oplus\big(F_k(r)\oplus m\big)=m$。<span class="muted">（补充说明）</span>

::: ex [补充说明] 直觉：每次加密都是一次“新的一次一密”
- $r$ **明文发送**，并不需要保密；
- 只要 $r$ 是新鲜的（从未被用过），$F_k(r)$ 在敌手眼中就像一个全新的均匀 pad，$F_k(r)\oplus m$ 就像一次一密；
- 代价：密文长度是明文的 **2 倍**（$2n$ 位）；而且只有当某次的 $r$ 与以前**重复**时，才会出现两次加密共用一个 pad 的危险——这正是证明中 $q(n)/2^n$ 的来源。
:::

<L05EncAnim />

::: tldr
$\mathsf{Enc}_k(m)=\langle r,F_k(r)\oplus m\rangle$：用新鲜随机数 $r$ 让每次加密都有自己的伪随机 pad。
:::

## 5.5 安全性证明：定理 3.31

::: prin 定理 3.31 @P24
若 $F$ 是伪随机函数，则构造 3.30 是针对长度为 $n$ 的消息的 **CPA 安全**私钥加密方案。
:::

**证明思路** <Src p="24" />：构造一个与构造 3.30 的方案 $\Pi$ 几乎一样的方案 $\tilde\Pi=(\widetilde{\mathsf{Gen}},\widetilde{\mathsf{Enc}},\widetilde{\mathsf{Dec}})$，唯一区别是把 $F_k$ 换成**真随机函数** $f$（$\widetilde{\mathsf{Gen}}$ 均匀选 $f\in\mathsf{Func}_n$，$\widetilde{\mathsf{Enc}}_f(m)=\langle r,f(r)\oplus m\rangle$）。然后分两步：

$$\underbrace{\Pr[\mathsf{PrivK}^{\mathsf{cpa}}_{\mathcal{A},\Pi}(n)=1]}_{\text{用 }F_k}\ \overset{\text{第 1 步：}\pm\mathsf{negl}}{\approx}\ \underbrace{\Pr[\mathsf{PrivK}^{\mathsf{cpa}}_{\mathcal{A},\tilde\Pi}(n)=1]}_{\text{用 }f}\ \overset{\text{第 2 步}}{\le}\ \frac12+\frac{q(n)}{2^n}.$$

固定任意 PPT 敌手 $\mathcal{A}$，设 $q(n)$ 是 $\mathcal{A}$ 发出的加密查询次数的（多项式）上界。

<L05ProofMap />

### 5.5.1 第 1 步：$\Pi$ 与 $\tilde\Pi$ 不可区分 <Src p="24" />

::: prin 断言 1 @P24
存在可忽略函数 $\mathsf{negl}$ 使
$$\Big|\Pr\big[\mathsf{PrivK}^{\mathsf{cpa}}_{\mathcal{A},\Pi}(n)=1\big]-\Pr\big[\mathsf{PrivK}^{\mathsf{cpa}}_{\mathcal{A},\tilde\Pi}(n)=1\big]\Big|\le\mathsf{negl}(n).$$
:::

课件只说“由 PRF 与随机函数的不可区分性”即得；下面补全**规约**。<span class="muted">（补充说明）</span>

**构造区分器 $D$**：$D$ 输入 $1^n$，拥有对某个函数 $\mathcal{O}:\{0,1\}^n\to\{0,1\}^n$ 的预言机访问（$\mathcal{O}$ 要么是 $F_k$，要么是 $f$，$D$ 不知道是哪个），运行 $\mathcal{A}(1^n)$：

1. 每当 $\mathcal{A}$ 询问加密预言机 $m$：$D$ 均匀选 $r\in\{0,1\}^n$，查询 $y:=\mathcal{O}(r)$，回答 $\langle r,\ y\oplus m\rangle$；
2. 当 $\mathcal{A}$ 输出 $m_0,m_1$：$D$ 选均匀比特 $b$ 和均匀 $r^*\in\{0,1\}^n$，查询 $y^*:=\mathcal{O}(r^*)$，把 $c^*:=\langle r^*,\ y^*\oplus m_b\rangle$ 交给 $\mathcal{A}$；
3. 之后继续按第 1 步回答 $\mathcal{A}$ 的查询；
4. $\mathcal{A}$ 输出 $b'$。若 $b'=b$，$D$ 输出 1，否则输出 0。

**逐步分析**：

- **$D$ 是 PPT**：$D$ 的工作 = 运行 PPT 的 $\mathcal{A}$ + 至多 $q(n)+1$ 次选随机数、查预言机、异或，均为多项式时间。
- **$\mathcal{O}=F_k$（$k$ 均匀）时**：$D$ 给 $\mathcal{A}$ 的每个回答都是 $\langle r,F_k(r)\oplus m\rangle=\mathsf{Enc}_k(m)$，挑战密文是 $\mathsf{Enc}_k(m_b)$，$k$ 的分布与 $\mathsf{Gen}$ 相同。所以 $\mathcal{A}$ 的视图与在 $\mathsf{PrivK}^{\mathsf{cpa}}_{\mathcal{A},\Pi}(n)$ 中**同分布**，且“$D$ 输出 1”恰是“$\mathcal{A}$ 成功”：
$$\Pr\big[D^{F_k(\cdot)}(1^n)=1\big]=\Pr\big[\mathsf{PrivK}^{\mathsf{cpa}}_{\mathcal{A},\Pi}(n)=1\big].$$
- **$\mathcal{O}=f$（$f$ 均匀）时**：同理 $\mathcal{A}$ 的视图与在 $\mathsf{PrivK}^{\mathsf{cpa}}_{\mathcal{A},\tilde\Pi}(n)$ 中同分布：
$$\Pr\big[D^{f(\cdot)}(1^n)=1\big]=\Pr\big[\mathsf{PrivK}^{\mathsf{cpa}}_{\mathcal{A},\tilde\Pi}(n)=1\big].$$
- **用 PRF 定义**：$F$ 是 PRF、$D$ 是 PPT ⇒ $|\Pr[D^{F_k}(1^n)=1]-\Pr[D^{f}(1^n)=1]|\le\mathsf{negl}(n)$。把上面两个等式代入，即得断言 1。

### 5.5.2 第 2 步：分析理想方案 $\tilde\Pi$ <Src p="25–26" />

::: prin 断言 2 @P25
$$\Pr\big[\mathsf{PrivK}^{\mathsf{cpa}}_{\mathcal{A},\tilde\Pi}(n)=1\big]\le\frac12+\frac{q(n)}{2^n},$$
其中 $q(n)$ 是 $\mathcal{A}$ 发出的加密查询次数的上界。
:::

记挑战密文为 $c^*=\langle r^*,s^*\rangle$，$s^*=f(r^*)\oplus m_b$。定义事件 **Repeat**（课件称 “≥1 query matches”）：$r^*$ 等于 $\mathcal{A}$ 的**某次**加密查询（挑战之前或之后）所用的随机串 $r_i$。

**(a) 若 Repeat 不发生**：$f(r^*)$ 这个值除了在挑战密文里，没有在 $\mathcal{A}$ 视图的任何地方出现过（其他密文用的都是 $f(r_i)$，$r_i\neq r^*$）。由于 $f$ 是真随机函数（惰性采样视角：$f(r^*)$ 是独立于其他所有值新采样的均匀串），$f(r^*)$ 在 $\mathcal{A}$ 看来是均匀的，于是 $s^*=f(r^*)\oplus m_b$ 无论 $b=0$ 还是 $1$ 都是均匀串，与 $b$ 独立——这就是一次一密。所以
$$\Pr\big[\mathsf{PrivK}^{\mathsf{cpa}}_{\mathcal{A},\tilde\Pi}(n)=1\ \big|\ \overline{\textsf{Repeat}}\big]=\frac12.$$

**(b) Repeat 的概率**：$r^*$ 是均匀选取的，与 $\mathcal{A}$ 的查询选用的 $r_1,\dots,r_{q}$ 相互独立。对每个 $i$，$\Pr[r^*=r_i]=2^{-n}$；由**联合界**（union bound），
$$\Pr[\textsf{Repeat}]\le\sum_{i=1}^{q(n)}\Pr[r^*=r_i]=\frac{q(n)}{2^n}.$$

**(c) 全概率公式**（课件 P26 的推导）：

$$
\begin{aligned}
\Pr\big[\mathsf{PrivK}^{\mathsf{cpa}}_{\mathcal{A},\tilde\Pi}=1\big]
&=\Pr\big[\mathsf{PrivK}^{\mathsf{cpa}}_{\mathcal{A},\tilde\Pi}=1\mid\overline{\textsf{Repeat}}\big]\cdot\Pr\big[\overline{\textsf{Repeat}}\big]
 +\Pr\big[\mathsf{PrivK}^{\mathsf{cpa}}_{\mathcal{A},\tilde\Pi}=1\mid\textsf{Repeat}\big]\cdot\Pr[\textsf{Repeat}]\\[2pt]
&\le\frac12\cdot1+1\cdot\frac{q(n)}{2^n}\\[2pt]
&=\frac12+\frac{q(n)}{2^n}.
\end{aligned}
$$

逐步依据：第一行是对事件 Repeat 的全概率公式；第二行中，第一项用 (a) 的 $\tfrac12$ 并放大 $\Pr[\overline{\textsf{Repeat}}]\le1$，第二项把条件成功概率放大到 $1$（发生 Repeat 时敌手可能完全知道 $b$），再用 (b) 的 $\Pr[\textsf{Repeat}]\le q(n)/2^n$。

### 5.5.3 第 3 步：合并 <Src p="27" />

由断言 1 得 $\Pr[\mathsf{PrivK}^{\mathsf{cpa}}_{\mathcal{A},\Pi}(n)=1]\le\Pr[\mathsf{PrivK}^{\mathsf{cpa}}_{\mathcal{A},\tilde\Pi}(n)=1]+\mathsf{negl}(n)$，再代入断言 2：

$$\Pr\big[\mathsf{PrivK}^{\mathsf{cpa}}_{\mathcal{A},\Pi}(n)=1\big]\le\frac12+\frac{q(n)}{2^n}+\mathsf{negl}(n).$$

$q(n)$ 是多项式（$\mathcal{A}$ 是 PPT，查询次数不超过其运行时间），所以 $q(n)/2^n$ 可忽略；两个可忽略函数之和仍可忽略。因此没有 PPT 敌手能以不可忽略的优势（相对 $\tfrac12$）赢得 CPA 实验，**定理得证**。∎

::: qa 为什么第 2 步不需要“PPT”这个条件？
因为 $\tilde\Pi$ 用的是**真随机函数**，断言 2 的论证只用到了“$f(r^*)$ 在不发生 Repeat 时均匀”和“查询次数 $\le q(n)$”，对计算能力无限、但只查 $q(n)$ 次的敌手也成立。**计算假设只在第 1 步（PRF ↔ 随机函数）用到一次**。这正是“先换成理想对象、再做信息论分析”这一证明范式的妙处。<span class="muted">（补充说明）</span>
:::

::: tldr
证明 = 规约（把 $F_k$ 换成 $f$，误差 negl）+ 信息论分析（只有 $r^*$ 撞上查询过的 $r$ 才泄露，概率 $\le q/2^n$）。
:::

## 5.6 CPA 安全蕴含多次加密下的 CPA 安全

::: prin 定理 3.24 @P28
任何 CPA 安全的私钥加密方案，在多次加密下也是 CPA 安全的。
:::

**CPA 安全的一大优势**：只要证明方案对**单次**加密是 CPA 安全的，就能“**免费**”得到它对多次加密也是 CPA 安全的。

为什么成立？课件给出的直观 <Src p="28" />：

- CPA 安全的加密**不是确定性的**（5.2 节的 Q）；
- CPA 不可区分实验中敌手能看到的东西，**涵盖了**多次加密 CPA 实验中敌手能看到的东西：敌手可以用加密预言机自己生成任意多条“额外”密文。

下面给出严格表述与证明梗概。<span class="muted">（补充说明，参见教材 §3.4.2）</span>

::: def [补充] 多次加密的 CPA 实验 $\mathsf{PrivK}^{\mathsf{LR\text{-}cpa}}_{\mathcal{A},\Pi}(n)$
1. $k\leftarrow\mathsf{Gen}(1^n)$，选均匀 $b\in\{0,1\}$；
2. $\mathcal{A}$ 得到 $1^n$ 与“左右预言机” $\mathsf{LR}_{k,b}(\cdot,\cdot)$ 的访问：输入等长的 $m_0,m_1$，返回 $\mathsf{Enc}_k(m_b)$；
3. $\mathcal{A}$ 输出 $b'$，若 $b'=b$ 则实验输出 1。

（注意 $\mathsf{LR}_{k,b}(m,m)=\mathsf{Enc}_k(m)$，所以加密预言机已包含在内。）若对所有 PPT $\mathcal{A}$ 有 $\Pr[\mathsf{PrivK}^{\mathsf{LR\text{-}cpa}}_{\mathcal{A},\Pi}(n)=1]\le\tfrac12+\mathsf{negl}(n)$，称 $\Pi$ 在多次加密下 CPA 安全。
:::

**证明梗概（混合论证）**：设 $\mathcal{A}$ 至多发出 $t=t(n)$ 次 LR 查询，第 $j$ 次为 $(m_{0,j},m_{1,j})$。定义混合实验 $H^{(i)}$（$0\le i\le t$）：前 $i$ 次查询回答 $\mathsf{Enc}_k(m_{1,j})$，其余回答 $\mathsf{Enc}_k(m_{0,j})$。记 $p_i=\Pr[\mathcal{A}\text{ 在 }H^{(i)}\text{ 中输出 }1]$。则 $H^{(0)}$ 就是 $b=0$ 的世界，$H^{(t)}$ 就是 $b=1$ 的世界，且

$$\Pr\big[\mathsf{PrivK}^{\mathsf{LR\text{-}cpa}}_{\mathcal{A},\Pi}=1\big]=\tfrac12(1-p_0)+\tfrac12 p_t=\tfrac12+\tfrac12(p_t-p_0).$$

构造单次 CPA 敌手 $\mathcal{A}'$：均匀选 $i\in\{1,\dots,t\}$，运行 $\mathcal{A}$；第 $j<i$ 次查询用自己的加密预言机回答 $\mathsf{Enc}_k(m_{1,j})$，第 $j>i$ 次回答 $\mathsf{Enc}_k(m_{0,j})$，第 $i$ 次把 $(m_{0,i},m_{1,i})$ 作为**自己的挑战**提交，把挑战密文转给 $\mathcal{A}$；最后输出 $\mathcal{A}$ 的输出。

- 挑战比特为 0 时，$\mathcal{A}$ 看到的恰是 $H^{(i-1)}$；为 1 时恰是 $H^{(i)}$。于是
$$\Pr[\mathcal{A}'\text{ 输出 }1\mid b=1]-\Pr[\mathcal{A}'\text{ 输出 }1\mid b=0]=\frac1t\sum_{i=1}^{t}(p_i-p_{i-1})=\frac{p_t-p_0}{t}\quad(\text{望远镜求和}).$$
- 而 $\Pr[\mathsf{PrivK}^{\mathsf{cpa}}_{\mathcal{A}',\Pi}=1]=\tfrac12+\tfrac12\cdot\frac{p_t-p_0}{t}$。由 $\Pi$ 的 CPA 安全，$\frac{p_t-p_0}{t}\le 2\,\mathsf{negl}(n)$，所以 $p_t-p_0\le 2t(n)\,\mathsf{negl}(n)$，仍可忽略（$t$ 为多项式）。
- 代回得 $\Pr[\mathsf{PrivK}^{\mathsf{LR\text{-}cpa}}_{\mathcal{A},\Pi}=1]\le\tfrac12+t(n)\,\mathsf{negl}(n)$。∎

::: ex [推论] 任意长消息的加密
构造 3.30 只能加密 $n$ 位消息。由定理 3.24，把长消息切成 $n$ 位块 $m_1,\dots,m_\ell$，**每块独立用构造 3.30 加密**，得到 $\langle r_1,F_k(r_1)\oplus m_1\rangle,\dots,\langle r_\ell,F_k(r_\ell)\oplus m_\ell\rangle$，就是对任意长消息 CPA 安全的方案（密文长度为明文 2 倍；后续课程的工作模式会更高效）。<span class="muted">（补充说明）</span>
:::

::: tldr
CPA 安全 ⇒ 多次加密 CPA 安全（混合论证，损失因子 $t$）。所以只需对单条消息证明 CPA 安全。
:::

## 5.7 伪随机置换

### 5.7.1 置换与随机置换

同样先看 $\{0,1\}$ 上的置换 <Src p="31" />：

<FigGrid>
<Fig src="/img/05/p016a.jpg" cap="图 6：{0,1} 上的一个置换（与图 2 为同一张图：0↦1、1↦0 恰好是双射）" p="31" />

::: def 置换、$\mathsf{Perm}_n$ 与随机置换 @P32
- **置换**（函数）是从 $\{0,1\}^n$ 到 $\{0,1\}^n$ 的**双射**（一一映射）。
- 记 $\mathsf{Perm}_n$ 为 $\{0,1\}^n$ 上所有置换的集合，其大小为
$$|\mathsf{Perm}_n|=(2^n)!=2^n\cdot(2^n-1)\cdots1.$$
- $\{0,1\}^n$ 上的**随机置换** $f$ 是从 $\mathsf{Perm}_n$ 中均匀随机选出的置换。
:::

<span class="muted">（补充说明）对比：$n=1$ 时 $|\mathsf{Func}_1|=4$、$|\mathsf{Perm}_1|=2$；$n=2$ 时 $|\mathsf{Func}_2|=4^4=256$、$|\mathsf{Perm}_2|=4!=24$。置换只是函数中“没有碰撞”的那一小部分。</span>

### 5.7.2 伪随机置换 <Src p="33" />

::: def 带密钥置换与伪随机置换 PRP @P33
- 设 $F$ 是带密钥函数。若 $l_{in}=l_{out}$，且对**每个** $k$，函数 $F_k:\{0,1\}^{l_{in}}\to\{0,1\}^{l_{out}}$ 都是一一映射，称 $F$ 为**带密钥置换**（<span class="en">keyed permutation</span>），称 $l_{in}$ 为 $F$ 的**分组长度**（<span class="en">block length</span>）。
- 若给定 $k,x$ 能在多项式时间内算出 $F_k(x)$，给定 $k,y$ 能在多项式时间内算出逆 $F_k^{-1}(y)$，称 $F$ 是**高效的**。
- 若**没有**高效算法能区分 $F_k$（$k$ 均匀）与随机置换（从 $\mathsf{Perm}_n$ 中均匀选取的函数），称 $F_k$ 是**伪随机置换**（<span class="en">Pseudorandom Permutation, PRP</span>）。

形式化即把定义 3.25 中的 $f\in\mathsf{Func}_n$ 换成 $f\in\mathsf{Perm}_n$：$|\Pr[D^{F_k(\cdot)}(1^n)=1]-\Pr[D^{f(\cdot)}(1^n)=1]|\le\mathsf{negl}(n)$。<span class="muted">（补充说明）</span>
:::

::: tldr
PRP = 高效可逆的带密钥置换，与**随机置换**不可区分。
:::

## 5.8 PRP 与 PRF

::: prin 命题 3.27：分组足够长时，伪随机置换也是伪随机函数 @P35
若 $F$ 是伪随机置换，且 $l_{in}\ge n$，则 $F$ 也是伪随机函数。
:::

**直观** <Src p="35" />：除非观察到两个不同的 $x,y$ 满足 $f(x)=f(y)$（**碰撞**），一个均匀随机**函数**看起来和一个均匀随机**置换**完全一样；而用多项式次查询找到这样一对值的概率，在分组长度足够大时是可忽略的。

<span class="muted">注：课件原话为 “it is indistinguishable from a random function or a PRF”，严格说应为“与随机函数不可区分，因而是 PRF”。</span>

**证明梗概**（补充说明）：设 PPT 区分器 $D$ 至多查询 $q=q(n)$ 次（不妨设查询互不相同）。

1. 惰性采样随机函数 $f$：每个新查询的答案在 $\{0,1\}^{l_{in}}$ 中均匀采样；惰性采样随机置换 $\pi$：每个新查询的答案在**尚未用过**的值中均匀采样。只要 $f$ 的答案没有出现碰撞（事件 Coll 不发生），两者给 $D$ 的答案分布完全相同，因此
$$\Big|\Pr[D^{\pi}=1]-\Pr[D^{f}=1]\Big|\le\Pr[\textsf{Coll}]\le\binom{q}{2}\frac{1}{2^{l_{in}}}=\frac{q(q-1)}{2^{l_{in}+1}}\quad(\text{生日界 + 联合界}).$$
2. 三角不等式：
$$\Big|\Pr[D^{F_k}=1]-\Pr[D^{f}=1]\Big|\le\underbrace{\Big|\Pr[D^{F_k}=1]-\Pr[D^{\pi}=1]\Big|}_{\le\,\mathsf{negl}(n)\ (F\text{ 是 PRP})}+\underbrace{\Big|\Pr[D^{\pi}=1]-\Pr[D^{f}=1]\Big|}_{\le\,q^2/2^{l_{in}+1}}.$$
3. $l_{in}\ge n$ 且 $q$ 为多项式 ⇒ $q^2/2^{l_{in}+1}\le q^2/2^{n+1}$ 可忽略。所以 $F$ 是 PRF。∎

<L05PrpBirthday />

::: qa 反过来，PRF 一定是 PRP 吗？
不一定，甚至**连置换都不一定是**：PRF 只要求像随机函数，而随机函数通常不是双射，$F_k$ 也不必可逆。（教材后续会用 Feistel 网络把 PRF 变成 PRP。）<span class="muted">（补充说明）</span>
:::

::: tldr
随机置换与随机函数的唯一区别是“有无碰撞”，生日界 $q^2/2^{l+1}$ 可忽略 ⇒ 分组够长的 PRP 可直接当 PRF 用。
:::

## 5.9 强伪随机置换与分组密码

### 5.9.1 强伪随机置换 <Src p="37" />

诚实一方常常除了 $F_k$ 之外还需要计算逆函数 $F_k^{-1}$（例如解密），因此我们也应假设**敌手能做这样的计算**，并要求：**即使区分器还额外拥有对逆置换的预言机访问**，$F_k$ 仍与均匀置换不可区分。具有这种性质的 $F$ 称为**强伪随机置换**。

<span class="muted">注：课件原文 “If F has such probability” 应为 “such property”（性质）。</span>

::: def 强伪随机置换（定义 3.28） @P37
设 $F:\{0,1\}^*\times\{0,1\}^*\to\{0,1\}^*$ 是高效的、保长的带密钥置换。若对所有 PPT 区分器 $D$，存在可忽略函数 $\mathsf{negl}$ 使得

$$\Big|\Pr\big[D^{F_k(\cdot),\,F_k^{-1}(\cdot)}(1^n)=1\big]-\Pr\big[D^{f(\cdot),\,f^{-1}(\cdot)}(1^n)=1\big]\Big|\le\mathsf{negl}(n),$$

则称 $F$ 是**强伪随机置换**（<span class="en">strong PRP</span>）。其中第一个概率取自 $k\in\{0,1\}^n$ 的均匀选取和 $D$ 的随机性，第二个概率取自 $f\in\mathsf{Perm}_n$ 的均匀选取和 $D$ 的随机性。
:::

::: ex [补充说明] 强 PRP 严格强于 PRP
强 PRP 显然是 PRP（不用逆预言机即可）。反之不成立：经典结果（Luby–Rackoff）表明 **3 轮** Feistel 网络是 PRP，但给了逆预言机就能被区分；**4 轮**才是强 PRP。
:::

### 5.9.2 分组密码 <Src p="38" />

实践中，**分组密码**（<span class="en">block cipher</span>）被设计为（强）伪随机置换 / PRF 的安全实例化，具有**固定的**密钥长度和分组长度。

<span class="muted">（补充说明）例如 AES：分组长度 128 位，密钥 128/192/256 位；DES：分组 64 位，密钥 56 位。由于参数固定，它们无法谈“渐近”意义上的可忽略，而是用“已知最好的攻击需要约 $2^{\text{密钥长度}}$ 次运算”来衡量（具体安全性）。AES 的 128 位分组配合命题 3.27，使它也能直接当 PRF 用于构造 3.30。</span>

::: tldr
强 PRP：连逆预言机也给敌手仍不可区分。分组密码（AES 等）就是强 PRP 的实际实例。
:::

## 5.10 PRF 与 PRG

::: def PRF → PRG @P40
由 PRF $F$ 可以很容易地为任意需要的 $l$ 构造 PRG $G$：
$$G(s)\overset{\text{def}}{=}F_s(\langle1\rangle)\,\|\,F_s(\langle2\rangle)\,\|\,\cdots\,\|\,F_s(\langle l\rangle),$$
其中 $\langle i\rangle$ 是整数 $i$ 的 $n$ 位二进制编码（课件写作 $F_s(1)\|\dots\|F_s(l)$）。取 $l\ge2$ 时输出长度 $ln>n$，确实是扩展的。
:::

**为什么伪随机**（补充说明）：若 PPT 的 $D$ 能以不可忽略优势区分 $G(s)$ 与均匀 $ln$ 位串，构造 PRF 区分器 $D'^{\mathcal{O}}$：查询 $\mathcal{O}(\langle1\rangle),\dots,\mathcal{O}(\langle l\rangle)$，拼接后交给 $D$ 并输出其结果。$\mathcal{O}=F_s$ 时 $D$ 看到 $G(s)$；$\mathcal{O}=f$ 时看到 $l$ 个**不同**输入上的真随机输出，即均匀的 $ln$ 位串。所以 $D'$ 的优势等于 $D$ 的优势，与 $F$ 是 PRF 矛盾。

::: def PRG → PRF（输入很短时） @P40
反过来，扩展因子为 $n\cdot2^{t(n)}$ 的 PRG $G$ 可以用来构造输入长度为 $t(n)$ 的 PRF：记 $y_0y_1y_2\cdots$ 为 $G(k)$ 的输出比特，把输入 $x\in\{0,1\}^{t(n)}$ 视为整数，令
$$F_k(x)=y_{x\cdot n}\,y_{x\cdot n+1}\cdots y_{x\cdot n+n-1},$$
即把 $G(k)$ 切成 $2^{t(n)}$ 个 $n$ 位块，$F_k(x)$ 取第 $x$ 块。这样得到 $F:\{0,1\}^n\times\{0,1\}^{t(n)}\to\{0,1\}^n$。

<span class="muted">注：课件原文为“构造 $F:\{0,1\}^n\times\{0,1\}^n\to\{0,1\}^{t(n)}$，$F_k(x)=y_{x\cdot t(n)}\cdots y_{x\cdot t(n)+t(n)-1}$”，把输入长度与输出长度写反了：若输入为 $n$ 位、每块 $t(n)$ 位，共需 $t(n)\cdot2^n$ 位，与扩展因子 $n\cdot2^{t(n)}$ 不符。与扩展因子一致的写法如上（亦即教材的写法）。另外，为了让 $G$ 能在多项式时间内输出 $n\cdot2^{t(n)}$ 位，需要 $t(n)=O(\log n)$。</span>
:::

**安全性直观**（补充说明）：$F_k$ 的整张函数表就是 $G(k)$；若把 $G(k)$ 换成均匀串，函数表就是均匀的——正是一个从 $\{0,1\}^{t(n)}$ 到 $\{0,1\}^n$ 的随机函数。区分 $F_k$ 与随机函数的 $D$ 可以直接转化为区分 $G(k)$ 与均匀串的区分器（它拿到整串后自己查表回答 $D$ 的查询）。

<L05PrgPrf />

::: ex [补充说明] PRF 到底存不存在？
- 上面的查表法只能得到输入长度 $O(\log n)$ 的 PRF。**GGM 构造**（Goldreich–Goldwasser–Micali）用长度加倍的 PRG $G(s)=G_0(s)\|G_1(s)$ 沿二叉树逐位下降：$F_k(x_1x_2\cdots x_n)=G_{x_n}(\cdots G_{x_2}(G_{x_1}(k))\cdots)$，从而由任意 PRG 得到**保长**的 PRF（演示 ③）。
- 结合 Luby–Rackoff（PRF → 强 PRP），有：**单向函数存在 ⟺ PRG 存在 ⟺ PRF 存在 ⟺ （强）PRP 存在**。实践中则直接**假设** AES 等分组密码是强 PRP。
:::

::: tldr
PRF ⇒ PRG：在固定输入上求值拼接。PRG ⇒ PRF：短输入可查表，保长需 GGM 树。两者存在性等价。
:::
