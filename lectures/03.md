## 3.1 信息论安全 vs 计算安全

::: def 两种安全观 @P4–8
计算安全对完美安全做了**两处放松**（two relaxations）：

- **信息论安全**（完美安全）<span class="en">Information-theoretically Secure / Perfectly Secure</span>：敌手的计算能力**不受限制**，但手里的信息不足以发动成功的攻击，所以**一定失败**。
- **计算安全** <span class="en">Computationally Secure</span>：敌手是**高效**的（放松 ①：只考虑计算能力有限的敌手）；它手里其实有足够信息，可能以**很小的概率成功**（放松 ②：允许极小的成功概率）。
:::

定义计算安全有两种途径 <Src p="7–8" />：

1. **具体方法** <span class="en">concrete approach</span>；
2. **渐近方法** <span class="en">asymptotic approach</span>——<span class="hl">本课只考虑这一种</span>。

::: def [补充说明] 具体方法：(t, ε)-安全
（课件只提了名字，这里按教材 3.1.1 节补充。）一个方案是 **$(t,\varepsilon)$-安全**的，如果任何运行时间不超过 $t$ 的敌手攻破它的概率都不超过 $\varepsilon$。

例：若攻击一个 $n$ 位密钥方案的最好办法就是穷举，那么试 $t$ 个密钥的敌手成功率约为 $t/2^n$。$n=128$、$t=2^{80}$ 时 $\varepsilon\approx 2^{-48}$。

具体方法给出的是实打实的数字，但“$t$ 用什么机器、什么计算模型衡量”很难说清；渐近方法把 $t$ 和 $\varepsilon$ 都写成安全参数 $n$ 的函数，只问它们的**增长趋势**，从而摆脱这些细节。
:::

<L03PolyExp />

::: tldr
计算安全 = 完美安全的两处放松：只防**高效**敌手，允许**极小**的成功概率。本课用渐近方法刻画这两点。
:::

## 3.3 高效敌手：PPT 算法

定义计算安全时，我们只关注**高效敌手** <span class="en">efficient adversaries</span>：如果系统能抵御高效敌手，它自然也能抵御“不高效”的敌手。<Src p="17" />

<Fig src="/img/03/p017.jpg" cap="三类敌手：不高效的敌手（三轮车）、高效敌手（战斗机，本课关注）、“神一般”的敌手（计算能力无限，对应完美安全）" p="17" />

::: def 高效敌手 = PPT 算法 @P18–19
数字世界里的高效敌手 = **随机化算法** + **多项式时间有界** = **概率多项式时间**（Probabilistic Polynomial-Time）算法，简称 **PPT 算法**。

- **随机化算法**：目前被公认为实际计算机可行且强大的计算方式；
- **多项式时间有界**：给定安全参数 $n$，算法运行不超过 $\mathrm{poly}(n)$ 步，其中 $\mathrm{poly}(n)$ 是 $n$ 的多项式，即可写成
$$\mathrm{poly}(n) = a_k n^k + a_{k-1}n^{k-1} + \cdots + a_1 n + a_0 .$$
:::

::: ex [补充说明] 为什么算法输入是 $1^n$
后面 $\mathsf{Gen}(1^n)$、敌手 $\mathcal A(1^n)$ 的输入都写成 $n$ 个 1 组成的串 $1^n$（一元表示）。原因是“多项式时间”按**输入长度**计量：输入 $1^n$ 长为 $n$，于是“关于输入长度多项式时间”恰好就是“关于 $n$ 多项式时间”。若输入二进制的 $n$（长度只有 $\log n$），$\mathrm{poly}(n)$ 步就成了输入长度的指数。
:::

::: qa 为什么是多项式时间有界？为什么不是 $2^n$ 或 $n^n$？ @P20–24
经验上，多项式时间的计算被认为是**可行的**（practical）。

- **例 1**：$10^8\cdot n^4$，$n=80$。2 GHz 计算机跑 $10^8\cdot n^4$ 个周期约 **3 周**。
- **例 2**：$2^n$，$n=89$。2 GHz 计算机（约 $2^{31}$ 周期/秒）跑 $2^{89}$ 个周期需 $2^{89}\cdot 2^{-31} = 2^{58}$ 秒——**宇宙自大爆炸以来的年龄就在 $2^{58}$ 秒这个量级**。

<span class="muted">（核算：$10^8\cdot 80^4\approx 4.1\times10^{15}$，除以 $2\times10^9$ 得 $2.05\times10^6$ 秒 ≈ 23.7 天 ≈ 3.4 周；宇宙年龄 $1.38\times10^{10}$ 年 ≈ $4.4\times10^{17}$ 秒 ≈ $2^{58.6}$ 秒。）</span>
:::

::: ex [补充说明] 多项式的“封闭性”
选多项式还有一个理论上的好处：多项式经过加、乘、复合仍是多项式。所以“PPT 算法调用另一个 PPT 算法多项式次”仍是 PPT——后面的规约证明正是靠这一点保证构造出的新敌手依然“高效”。
:::

::: tldr
高效敌手 = PPT 算法：可以抛硬币，运行步数不超过 $n$ 的某个多项式。
:::

## 3.4 可忽略的成功概率

### 3.4.1 为什么要允许成功概率？

::: qa 为什么要允许敌手以可忽略的概率成功？ @P25–27
因为完美保密的代价太大，例如**密钥长度不能短于消息长度**（第 02 讲的 $\lvert\mathcal K\rvert\ge\lvert\mathcal M\rvert$）。
:::

::: qa “可忽略的成功概率”是什么意思？ @P25–27
给定安全参数 $n$，敌手的攻击成功概率不超过某个 $\mathrm{negl}(n)$。
:::

::: exam [考点] 期中 Q1（2025）
“举一个完美保密的加密算法（OTP），为什么实际中通常不用？”参考答案：**密钥管理困难**（每次通信都要共享与消息等长的真随机密钥且不能重用）、**密钥分发问题**（安全传送大量密钥本身就需要安全信道）、**存储与带宽开销大**。这正是本讲放松安全要求的动机。
:::

### 3.4.2 超多项式函数与可忽略函数

::: def 超多项式函数 Superpolynomial @P28
函数 $\mathrm{superpoly}(\cdot)$ 是**超多项式**的，当且仅当对每个常数 $c$，当 $n$ 充分大时都有
$$\mathrm{superpoly}(n) > n^c .$$
“充分大”是指：对每个 $c$，存在 $N_c$，使得不等式对所有 $n\ge N_c$ 成立。

可忽略函数是超多项式函数的倒数，反之亦然。<span class="muted">（不严谨：可忽略函数取值于非负实数，$\mathrm{negl}(n)=0$ 也是可忽略的，但它没有倒数；严格说只对取正值的函数成立。）</span>
:::

::: def 可忽略函数 negl(n)（定义 1.1） @P29–30
函数 $\mathrm{negl}(\cdot)$：$\mathbb N\to\mathbb R_{\ge 0}$ 是**可忽略的**（negligible），如果对**每个**正多项式 $p$，存在 $N$，使得对所有整数 $n > N$，
$$\mathrm{negl}(n) < \frac{1}{p(n)} .$$
:::

::: def 等价形式（定义 1.2） @P29–30
函数 $\mathrm{negl}(\cdot)$：$\mathbb N\to\mathbb R_{\ge 0}$ 是可忽略的，如果对**每个**正整数 $c$，存在 $N_c$，使得对所有整数 $n > N_c$，
$$\mathrm{negl}(n) < \frac{1}{n^c} .$$

<span class="muted">（补充说明：两者等价，因为任何正多项式 $p$ 都满足 $p(n)\le n^c$（$c$ 取次数加 1，$n$ 充分大）；反过来 $n^c$ 本身就是正多项式。）</span>
:::

一句话：**可忽略 = 比任何多项式的倒数都衰减得快**。量词顺序是关键——先给定 $c$，再找 $N_c$；$N_c$ 可以随 $c$ 变大。

### 3.4.4 判断可忽略：三道题

::: qa 你能证明 $1/2^n$ 是可忽略的吗？ @P35
**证明**：任给正整数 $c$，要找 $N_c$，使 $n > N_c$ 时 $\dfrac{1}{2^n} < \dfrac{1}{n^c}$，即 $2^n > n^c$，即 $n > c\log_2 n$。

$$
\begin{aligned}
c\log_2 n &= c\cdot\frac{\ln n}{\ln 2} \le c\cdot\frac{\sqrt n}{\ln 2} && \text{（对一切 } n\ge 1\text{，}\ln n\le\sqrt n\text{）}\\
&< 2c\sqrt n && (1/\ln 2\approx 1.443 < 2)\\
&\le n && \text{（当 } \sqrt n\ge 2c\text{，即 } n\ge 4c^2\text{）}
\end{aligned}
$$

逐步依据：第一行用 $\ln x\le\sqrt x$（令 $h(x)=\sqrt x-\ln x$，$h'(x)=\frac{1}{2\sqrt x}-\frac1x$，在 $x=4$ 取最小值 $h(4)=2-\ln 4>0$）；第二行是常数放大；第三行两边同除 $\sqrt n$ 即得条件。

所以取 $N_c = 4c^2$：当 $n > N_c$ 时 $c\log_2 n < n$，即 $\dfrac1{2^n} < \dfrac1{n^c}$。由定义 1.2，$1/2^n$ 可忽略。∎
:::

::: qa 你能证明 $1/n$ **不是**可忽略的吗？ @P36
**证明**：可忽略的否定是：**存在**正整数 $c$，使得对**任意** $N$，都**存在** $n > N$ 满足 $f(n)\ge \dfrac{1}{n^c}$。

取 $c=1$：对所有 $n\ge 1$ 都有 $\dfrac1n \ge \dfrac1{n^1}$（取等号），所以 $\dfrac1n < \dfrac1{n}$ 对任何 $n$ 都不成立，更不可能“对所有 $n>N_1$ 成立”。故 $1/n$ 不可忽略。∎

<span class="muted">（同理，任何多项式的倒数 $1/p(n)$ 都不可忽略。）</span>
:::

::: qa $1/n!$ 是可忽略的吗？能证明吗？ @P37
**是**。

**证明**：当 $n\ge 1$ 时，$n! = 1\cdot 2\cdot 3\cdots n$ 中从 $2$ 到 $n$ 的 $n-1$ 个因子都 $\ge 2$，所以 $n!\ge 2^{n-1}$；当 $n\ge 3$ 时至少有一个因子 $3>2$，不等式严格：
$$\frac{1}{n!} < \frac{2}{2^n}\qquad (n\ge 3).$$

由上一题，$1/2^n$ 可忽略；由下面命题 1 第 3 条（取多项式 $p(n)=2$），$2/2^n$ 可忽略；再由命题 1 第 1 条（被可忽略函数从上方压住），$1/n!$ 可忽略。∎
:::

### 3.4.5 可忽略函数的性质

::: prin 命题 1 @P38–39
设 $\mathrm{negl}_1$、$\mathrm{negl}_2$ 是可忽略函数，则：

1. 若存在整数 $N_c$ 使 $f(n) < \mathrm{negl}_1(n)$ 对所有 $n\ge N_c$ 成立，则 $f(n)$ 可忽略；
2. $\mathrm{negl}_3(n) = \mathrm{negl}_1(n) + \mathrm{negl}_2(n)$ 也可忽略；
3. 对任意正多项式 $p$，$\mathrm{negl}_4(n) = p(n)\cdot\mathrm{negl}_1(n)$ 可忽略。

第 3 条意味着：<span class="hl">“重复直到成功”的策略可以被挫败</span>。
:::

下面补全三条的证明（课件未给出）。都用定义 1.2。

**(1)** 任给 $c$。因 $\mathrm{negl}_1$ 可忽略，存在 $N'$ 使 $n>N'$ 时 $\mathrm{negl}_1(n) < 1/n^c$。于是当 $n > \max(N', N_c)$ 时
$$f(n) < \mathrm{negl}_1(n) < \frac1{n^c}.$$
（$f$ 需取非负值，这在定义域约定里已隐含。）∎

**(2)** 任给 $c$。对 $c+1$ 用两者的可忽略性：存在 $N_1,N_2$，使 $n>N_1$ 时 $\mathrm{negl}_1(n) < \frac{1}{n^{c+1}}$，$n>N_2$ 时 $\mathrm{negl}_2(n) < \frac{1}{n^{c+1}}$。当 $n > \max(N_1,N_2,2)$ 时
$$
\mathrm{negl}_1(n)+\mathrm{negl}_2(n) < \frac{2}{n^{c+1}} = \frac{2}{n}\cdot\frac1{n^c} \le \frac{1}{n^c}.
$$
最后一步用 $n\ge 2 \Rightarrow 2/n\le 1$。∎

**(3)** 设 $p(n)=\sum_{i=0}^{d}a_i n^i$，记 $a=\sum_i\lvert a_i\rvert$。当 $n\ge 1$ 时 $p(n)\le\sum_i\lvert a_i\rvert n^d = a\,n^d$。任给 $c$，对 $c+d+1$ 用 $\mathrm{negl}_1$ 的可忽略性：存在 $N'$ 使 $n>N'$ 时 $\mathrm{negl}_1(n) < \frac{1}{n^{c+d+1}}$。当 $n>\max(N', a, 1)$ 时
$$
p(n)\cdot\mathrm{negl}_1(n) < a n^d\cdot\frac{1}{n^{c+d+1}} = \frac{a}{n}\cdot\frac{1}{n^c} < \frac1{n^c}.
$$
∎

::: exam [考点] 期中 Q2（2025）：若 $g,h$ 都可忽略，下列 $f$ 是否**一定**可忽略？
| 函数 | 结论 | 理由 |
|---|---|---|
| $f(n)=(\log n)^{-\log n}$ | **是** | 见下方证明 |
| $f(n)=\binom{n}{c}^{-1}=\dfrac{c!\,(n-c)!}{n!}$（$c$ 为常数） | **否** | $\binom nc\le n^c$ 是多项式，取指数 $c$ 即否定 |
| $f(n)=f(n/3)$（$3\mid n$），否则 $3^{-n}$ | **否** | 在 $n=3^j$ 上 $f(3^j)=f(3^{j-1})=\cdots=f(1)=1/3$，无穷多次不小于 $1/n$ |
| $f(n)=g(n)+h(n)$ | **是** | 命题 1 第 2 条 |
| $f(n)=g(n)/h(n)$ | **否** | 反例 $g=2^{-n}$、$h=2^{-2n}$，$g/h=2^n$ |

**$(\log n)^{-\log n}$ 可忽略的证明**（助教讲解，取自然对数）：任给 $c>0$，要证 $n$ 充分大时 $(\log n)^{-\log n} < n^{-c}$，即
$$
\begin{aligned}
(\log n)^{\log n} > n^c
&\iff e^{\log n\cdot\log\log n} > e^{c\log n}\\
&\iff \log n\,(\log\log n - c) > 0\\
&\iff \log\log n > c\qquad(n>1).
\end{aligned}
$$
取 $N_c = e^{e^c}$，当 $n>N_c$ 时上式成立。∎

做这类题的通用心法：<span class="hl">写成 $f(n)=n^{-k(n)}$，看 $k(n)$ 是否趋于 $\infty$</span>；有反例时，往往只需找到**一个**子序列让 $k(n)$ 停在有限值（如第 3 小题的 $n=3^j$）。上面的“可忽略判定器”可以逐一试试。
:::

### 3.4.6 为什么可忽略的成功概率是安全的？

::: prin 两个主要理由 @P40–42
1. 可忽略的概率**非常小**，敌手成功的机会微乎其微；
2. 更重要的是，可忽略的成功概率能**挫败 PPT 敌手“重复直到成功”的策略**。
:::

::: def 对“重复直到成功”的分析 @P43–49
设敌手单次攻击的成功概率为 $p$，攻击 $n$ 次（简化起见，假设各次攻击**相互独立**且 $np<1$）：

$$
\begin{aligned}
\Pr[\,n\text{ 次中至少成功一次}\,]
&= 1-\Pr[\,\text{连续 } n \text{ 次失败}\,]\\
&= 1-\Pr[\,\text{第 1 次失败}\wedge\cdots\wedge\text{第 } n \text{ 次失败}\,]\\
&= 1-(1-p)^n\\
&= 1-\Big(1-np+\tfrac{n(n-1)}{2}p^2-\tfrac{n(n-1)(n-2)}{6}p^3+\cdots\Big)\\
&< np .
\end{aligned}
$$

由命题 1 的第 1、3 条，若 $p$ 可忽略，这个概率也可忽略。PPT 敌手最多只能重复 $p(n)$ 次（$p(n)$ 为任意多项式），成功机会**仍然可忽略**。
:::

::: warn [补充说明] 课件推导的几处不严谨
- 记号冲突：重复次数用了 $n$，又用 $n$ 表示安全参数，还用 $p$ 同时表示概率和多项式。规范写法是：单次成功率 $\varepsilon(n)$，重复 $q(n)$ 次。
- 由二项展开截断得到 “$< np$” 需要说明后面各项之和为负，课件跳过了；而且 $n=1$ 时是等号，应写 “$\le$”。
- 其实**不需要独立性，也不需要 $np<1$**：设 $E_i$ 为“第 $i$ 次成功”，由并集界（union bound）
$$\Pr\Big[\bigcup_{i=1}^{q(n)}E_i\Big]\le\sum_{i=1}^{q(n)}\Pr[E_i] = q(n)\cdot\varepsilon(n),$$
由命题 1 第 3 条它可忽略，再由第 1 条，至少成功一次的概率可忽略。
:::

<L03RepeatAttack />

::: tldr
可忽略 = 比任何 $1/\mathrm{poly}(n)$ 都小（终将）。它对加法、乘多项式封闭，所以 PPT 敌手无论怎么“多试几次”都无法把可忽略的成功率放大成不可忽略的。
:::

## 3.5 计算安全的渐近定义

::: def 计算安全的渐近定义（定义 1.3） @P50–52
一个方案是**安全的**，如果对每个执行某种**形式化规定类型**攻击的 PPT 敌手 $\mathcal A$，$\mathcal A$ 攻击成功的概率是**可忽略的**。
:::

::: def 等价形式（定义 1.4） @P50–52
一个方案是安全的，如果对每个执行某种形式化规定类型攻击的 PPT 敌手 $\mathcal A$，以及**每个**正多项式 $p$，存在整数 $N$，使得当 $n>N$ 时，$\mathcal A$ 攻击成功的概率小于 $\dfrac{1}{p(n)}$。

<span class="hl">对于 $n\le N$ 的取值，定义不作任何保证。</span>
:::

::: ex [补充说明] 两个“任意”
定义里有两个全称量词：**任意 PPT 敌手**（放松 ①）、**成功率可忽略**（放松 ②）。“形式化规定类型的攻击”留了一个空：下一部分就用“窃听者 + 不可区分实验”把它填上。另外 $N$ 可以依赖于 $\mathcal A$ 和 $p$——这也意味着实际部署时必须把 $n$ 选得足够大，渐近定义本身不告诉你多大才够（这正是具体方法的用武之地）。
:::

::: tldr
渐近安全：**每个** PPT 敌手的成功概率都是 $n$ 的可忽略函数。
:::

## 3.6 私钥加密方案（带安全参数）

::: def 私钥加密方案（定义 2.1） @P54–56
私钥加密方案是一个 PPT 算法三元组 $(\mathsf{Gen},\mathsf{Enc},\mathsf{Dec})$：

1. **密钥生成算法** $\mathsf{Gen}$：$k\leftarrow\mathsf{Gen}(1^n)$；
2. **加密算法** $\mathsf{Enc}$：$c\leftarrow\mathsf{Enc}_k(m)$，明文 $m\in\{0,1\}^*$；
3. **解密算法** $\mathsf{Dec}$：$m := \mathsf{Dec}_k(c)$。

若 $\mathsf{Enc}$ 只对 $m\in\{0,1\}^{l(n)}$ 有定义，则称 $(\mathsf{Gen},\mathsf{Enc},\mathsf{Dec})$ 是消息长度为 $l(n)$ 的**定长私钥加密方案**（fixed-length）。

几乎总是：$\mathsf{Gen}(1^n)$：$k\xleftarrow{\$}\{0,1\}^n$（均匀选取 $n$ 位密钥）。
:::

::: ex [补充说明] 记号与遗漏的正确性条件
- “$\leftarrow$” 表示随机算法的输出（可能带随机性），“$:=$” 表示确定性赋值——所以 $\mathsf{Dec}$ 是确定性的；“$\xleftarrow{\$}$” 表示从集合中均匀随机选取。
- 课件省略了**正确性**要求（教材定义 3.7）：对每个 $n$、每个由 $\mathsf{Gen}(1^n)$ 输出的 $k$、每个合法 $m$，都有 $\mathsf{Dec}_k(\mathsf{Enc}_k(m)) = m$。
:::

## 3.7 安全定义的动机

::: def 形式化安全定义需要两样东西 @P57–61
- **威胁模型**：例如**窃听敌手**（eavesdropping adversary）——只能看到密文；
- **安全目标**：？？？

直观的目标是：“**敌手无法从密文中获得关于明文的任何部分信息**”——这叫**语义安全**（semantic security），而<span class="hl">语义安全等价于不可区分性</span>（indistinguishability）。
:::

直接形式化“任何部分信息”很繁琐，所以我们改用一个等价、但好操作得多的游戏：**不可区分实验**。

## 3.8 不可区分实验 $\mathsf{PrivK}^{\mathsf{eav}}$

::: def 敌手不可区分实验 $\mathsf{PrivK}^{\mathsf{eav}}_{\mathcal A,\Pi}(n)$ @P62–66
1. 给定输入 $1^n$，$\mathcal A$ 输出一对消息 $m_0,m_1$，满足 $\lvert m_0\rvert=\lvert m_1\rvert$；
2. 挑战者收到 $m_0,m_1$，运行 $\mathsf{Gen}(1^n)$ 生成随机密钥 $k$，生成均匀比特 $b$，计算**挑战密文** $c\leftarrow\mathsf{Enc}_k(m_b)$ 并发给 $\mathcal A$；
3. $\mathcal A$ 输出一个比特 $b'$；
4. 若 $b=b'$，$\mathsf{PrivK}^{\mathsf{eav}}_{\mathcal A,\Pi}(n)=1$，否则为 $0$。若 $\mathsf{PrivK}^{\mathsf{eav}}_{\mathcal A,\Pi}(n)=1$，称 $\mathcal A$ **赢了**。
:::

与第 02 讲的完美不可区分实验相比，变化只有两处：实验带上了**安全参数** $n$（$\mathsf{Gen}(1^n)$、$\mathcal A(1^n)$），以及**要求 $\lvert m_0\rvert=\lvert m_1\rvert$**（任意长度的消息都允许，但密文一般会泄露长度，所以只要求不泄露长度以外的信息）。<span class="muted">（补充说明）</span>

## 3.9 EAV 安全（不可区分加密）

::: def 窃听者存在下的不可区分加密 / EAV 安全（定义 2.2） @P67–68
私钥加密方案 $\Pi=(\mathsf{Gen},\mathsf{Enc},\mathsf{Dec})$ 在窃听者存在下具有**不可区分加密**（indistinguishable encryptions in the presence of an eavesdropper），或称 **EAV 安全**，如果对每个 PPT 敌手 $\mathcal A$，存在可忽略函数 $\mathrm{negl}$，使得对所有 $n$，
$$\Pr\big[\mathsf{PrivK}^{\mathsf{eav}}_{\mathcal A,\Pi}(n)=1\big]\le\frac12+\mathrm{negl}(n),$$
其中概率取自 $\mathcal A$ 使用的随机性与实验中使用的随机性。

<span class="hl">敌手只能比随机猜测好“可忽略”的一点点。</span>
:::

::: def 等价定义（定义 2.3） @P69
$\Pi$ 是 EAV 安全的，如果对所有 PPT 敌手 $\mathcal A$，存在可忽略函数 $\mathrm{negl}$，使得对所有 $n$，
$$\Big\lvert\Pr\big[\mathsf{out}_{\mathcal A}(\mathsf{PrivK}^{\mathsf{eav}}_{\mathcal A,\Pi}(n,0))=1\big]-\Pr\big[\mathsf{out}_{\mathcal A}(\mathsf{PrivK}^{\mathsf{eav}}_{\mathcal A,\Pi}(n,1))=1\big]\Big\rvert\le\mathrm{negl}(n),$$
其中 $\mathsf{PrivK}^{\mathsf{eav}}_{\mathcal A,\Pi}(n,b)$（$b\in\{0,1\}$）表示在实验中使用**固定**的比特 $b$，$\mathsf{out}_{\mathcal A}(\cdot)$ 表示 $\mathcal A$ 的输出 $b'$。

<span class="hl">无论看到的是 $m_0$ 还是 $m_1$ 的密文，每个敌手的“行为几乎一样”，差别可忽略。</span>
:::

**两个定义等价的证明**（补充说明，课件只陈述了“等价”）。记 $p_b = \Pr[\mathsf{out}_{\mathcal A}(\mathsf{PrivK}^{\mathsf{eav}}_{\mathcal A,\Pi}(n,b))=1]$。因为 $b$ 均匀，

$$
\begin{aligned}
\Pr\big[\mathsf{PrivK}^{\mathsf{eav}}_{\mathcal A,\Pi}(n)=1\big]
&= \tfrac12\Pr[b'=0\mid b=0]+\tfrac12\Pr[b'=1\mid b=1] && \text{（全概率公式）}\\
&= \tfrac12(1-p_0)+\tfrac12\,p_1 && \text{（}p_b\text{ 的定义）}\\
&= \tfrac12+\tfrac12(p_1-p_0).
\end{aligned}
$$

- **（2.3 ⇒ 2.2）**：$\Pr[\mathsf{PrivK}=1]=\frac12+\frac12(p_1-p_0)\le\frac12+\frac12\lvert p_1-p_0\rvert\le\frac12+\frac12\mathrm{negl}(n)$，而 $\frac12\mathrm{negl}$ 仍可忽略。
- **（2.2 ⇒ 2.3）**：对 $\mathcal A$ 构造 $\bar{\mathcal A}$：与 $\mathcal A$ 完全相同，只是把最终输出取反。$\bar{\mathcal A}$ 仍是 PPT，且它的 $\bar p_b = 1-p_b$，于是 $\Pr[\mathsf{PrivK}_{\bar{\mathcal A}}=1]=\frac12+\frac12(p_0-p_1)$。对 $\mathcal A$ 和 $\bar{\mathcal A}$ 分别用定义 2.2：$p_1-p_0\le 2\,\mathrm{negl}_{\mathcal A}(n)$，$p_0-p_1\le 2\,\mathrm{negl}_{\bar{\mathcal A}}(n)$，所以 $\lvert p_1-p_0\rvert\le 2\big(\mathrm{negl}_{\mathcal A}(n)+\mathrm{negl}_{\bar{\mathcal A}}(n)\big)$，由命题 1 第 2、3 条可忽略。∎

::: warn [补充说明] 与完美不可区分的区别
第 02 讲的完美不可区分要求**所有**敌手（不限计算能力）的胜率**恰好**等于 $\frac12$；EAV 安全只要求 **PPT** 敌手的胜率**至多** $\frac12+\mathrm{negl}(n)$。两处放松正好对应 3.1 节的“两处放松”。
:::

## 3.10 语义安全

::: def 语义安全 Semantic Security @P70
有兴趣的同学可阅读教材第 3.2.2 节中语义安全的形式化处理。<span class="hl">它与不可区分性等价。</span>
:::

::: ex [补充说明] 语义安全的形式化（教材定义 3.12，简述）
$\Pi$ 在窃听者存在下是语义安全的，如果对每个 PPT 算法 $\mathcal A$，存在 PPT 算法 $\mathcal A'$，使得对任意输出等长消息的 PPT 采样算法 $\mathsf{Samp}$、任意多项式时间可计算的函数 $f$ 与 $h$，
$$\Big\lvert\Pr\big[\mathcal A(1^n,\mathsf{Enc}_k(m),h(m))=f(m)\big]-\Pr\big[\mathcal A'(1^n,\lvert m\rvert,h(m))=f(m)\big]\Big\rvert\le\mathrm{negl}(n),$$
其中 $m\leftarrow\mathsf{Samp}(1^n)$，$k\leftarrow\mathsf{Gen}(1^n)$。

读法：$h(m)$ 是敌手事先掌握的关于 $m$ 的“外部信息”，$f(m)$ 是它想学到的“部分信息”。**看了密文的 $\mathcal A$，并不比根本没看密文、只知道长度的 $\mathcal A'$ 猜得更准**——这就是“密文不泄露任何部分信息”。教材定理 3.13 证明它与 EAV 安全等价，所以以后都用更好操作的不可区分实验。
:::

::: tldr
EAV 安全：任何 PPT 窃听者在“$m_0$ 还是 $m_1$”游戏里的胜率至多 $\frac12+\mathrm{negl}(n)$；它等价于“输出差可忽略”的写法，也等价于语义安全。
:::

## 3.11 从一次性密码本出发

::: def 一次性密码本 One-Time Pad @P72–75
记 $a\oplus b$ 为两个二进制串按位异或（XOR）。一次性密码本如下：

1. 固定整数 $l>0$，$\mathcal M=\{0,1\}^l$，$\mathcal K=\{0,1\}^l$，$\mathcal C=\{0,1\}^l$；
2. $\mathsf{Gen}$：$K\xleftarrow{\$}\mathcal K$，即对每个 $k\in\mathcal K$，$\Pr[K=k]=1/2^l$；
3. $\mathsf{Enc}_K(M)$：$C := M\oplus K$。
:::

思路 <Src p="72–75" />：

- 均匀随机的密钥 $K$ 保证了**完美保密**（完全不可区分）。也许可以用一个**“只比均匀随机差可忽略一点”**的密钥流？
- 别忘了我们还想避开 OTP 的**“长密钥”**问题，所以必须使用**比密钥流更短**的密钥。
- 我们需要的正是：**伪随机生成器（PRG）**——把短的真随机种子“拉长”成看起来随机的长串。

## 3.12 伪随机生成器 PRG

::: def 伪随机生成器 Pseudo-random Generator（定义 3.1） @P76
设 $l$ 是多项式，$G$ 是一个**确定性**多项式时间算法，对任意 $n$ 和任意输入 $s\in\{0,1\}^n$，输出 $G(s)$ 是长度为 $l(n)$ 的串。称 $G$ 为**伪随机生成器**，如果满足：

1. **（扩展性 Expansion）** 对每个 $n$，$l(n) > n$；
2. **（伪随机性 Pseudo-randomness）** 对任意 PPT 算法 $D$，存在可忽略函数 $\mathrm{negl}$，使得
$$\big\lvert\Pr[D(G(s))=1]-\Pr[D(r)=1]\big\rvert\le\mathrm{negl}(n),$$
其中第一个概率取自 $s\in\{0,1\}^n$ 的均匀选取和 $D$ 的随机性，第二个概率取自 $r\in\{0,1\}^{l(n)}$ 的均匀选取和 $D$ 的随机性。

称 $l$ 为 $G$ 的**扩展因子**（expansion factor）。$D$ 称为**区分器**（distinguisher）。
:::

::: warn 关于 PRG 的三点说明 @P77–80
1. PRG **不是随机化算法**，它是**确定性**的——随机性全部来自种子 $s$；
2. 显然，PRG 输出的分布**不是**均匀随机的；
3. **暴力攻击**可以区分 PRG 输出与真随机，但需要 $O(2^n)$ 的时间。
:::

第 2、3 点的定量说明（补充说明）：

- $G$ 的值域 $\{G(s): s\in\{0,1\}^n\}$ 至多 $2^n$ 个元素，而 $\{0,1\}^{l(n)}$ 有 $2^{l(n)}\ge 2^{n+1}$ 个元素，所以值域至多占全部长串的 $2^{n-l(n)}\le\frac12$——**大多数长串 $G$ 根本输出不了**。
- 暴力区分器 $D_{\text{穷举}}$：输入 $w$，遍历所有 $s\in\{0,1\}^n$，若某个 $G(s)=w$ 则输出 1。于是 $\Pr[D(G(s))=1]=1$，$\Pr[D(r)=1]\le 2^{n-l(n)}\le\frac12$，优势至少 $\frac12$——但它要算 $2^n$ 次 $G$，**不是 PPT**，所以不违反定义。
- PRG 是否存在至今**没有证明**（它的存在蕴含 $\mathsf P\ne\mathsf{NP}$），我们把“存在 PRG”当作一个**假设**——这正是第 01 讲“原则 2：精确假设”的体现。

<L03PrgGame />

::: exam [考点] 期中 Q3（2025）：设 $G$ 是 PRG，下列 $G'$ 是否一定是 PRG？
1. $G'(s)=G(s_1s_2\cdots s_{\lvert s\rvert-1})\,\Vert\, s_{\lvert s\rvert}$：**是**。$s$ 均匀 ⇒ 前 $\lvert s\rvert-1$ 位均匀，所以 $G(\cdot)$ 部分伪随机；拼上的最后一位均匀且与前者独立，整体与均匀串不可区分。（扩展性：$l(n-1)+1\ge n+1>n$。）
2. $G'(s)=G(s)\oplus(s\,\Vert\,0^{\lvert G(s)\rvert-\lvert s\rvert})$：**不一定**。反例：取一个第一位直接输出 $s_1$ 的 PRG（如 $G(s)=s_1\Vert G_0(s_2\cdots s_n)$，同第 1 小题它仍是 PRG），则 $G'(s)$ 的第一位恒为 0。
3. 若 $s$ 中 1 的个数恰为 $\lfloor\lvert s\rvert/2\rfloor$ 则 $G'(s)=0^{\lvert G(s)\rvert}$，否则 $G'(s)=G(s)$：**不一定**。区分器“输出是否全 0”的优势约为 $\binom{n}{\lfloor n/2\rfloor}/2^n=\Theta(1/\sqrt n)$（Stirling 公式），不可忽略。<span class="muted">（更初等的下界：$\binom{n}{\lfloor n/2\rfloor}$ 是 $n+1$ 个二项式系数中最大的，而它们之和为 $2^n$，故该比值 $\ge\frac1{n+1}$。）</span>
4. $G'(s)=G(s\oplus 1^{\lvert s\rvert})$：**是**。$s$ 均匀 ⇒ $s\oplus1^{\lvert s\rvert}$ 也均匀，$G'(s)$ 与 $G(s)$ 同分布。

答题套路：说“是”时论证**输出分布**与某个已知伪随机分布相同或可归约；说“不一定”时给出**具体的 PPT 区分器**并算出它的不可忽略优势。
:::

## 3.13 用 PRG 构造定长加密方案

我们用 PRG 构造第一个（计算）安全的加密方案 <Src p="81" />——把 OTP 里的真随机密钥换成 $G(k)$：

<FigGrid>
<Fig src="/img/03/p081a.jpg" cap="用 PRG 加密：短密钥 → 伪随机生成器 → pad，与明文异或得到密文" p="81" />
<Fig src="/img/03/p081b.jpg" cap="构造 3.1（原文）" p="81" />
</FigGrid>

::: def 构造 3.1 @P82
设 $G$ 是扩展因子为 $l$ 的 PRG。定义消息长度为 $l$ 的私钥加密方案：

- $\mathsf{Gen}$：输入 $1^n$，均匀选取 $k\in\{0,1\}^n$ 作为密钥输出；
- $\mathsf{Enc}$：输入密钥 $k\in\{0,1\}^n$ 和消息 $m\in\{0,1\}^{l(n)}$，输出密文
$$c := G(k)\oplus m ;$$
- $\mathsf{Dec}$：输入密钥 $k\in\{0,1\}^n$ 和密文 $c\in\{0,1\}^{l(n)}$，输出明文
$$m := G(k)\oplus c .$$
:::

正确性（补充说明）：$\mathsf{Dec}_k(\mathsf{Enc}_k(m)) = G(k)\oplus G(k)\oplus m = m$。密钥只有 $n$ 位，却能加密 $l(n)>n$ 位的消息——绕开了完美保密 $\lvert\mathcal K\rvert\ge\lvert\mathcal M\rvert$ 的下界，代价是只对 PPT 敌手安全。

::: prin 定理 3.2 @P83–84
若 $G$ 是 PRG，则构造 3.1 是一个在窃听者存在下具有**不可区分加密**的定长私钥加密方案（即 EAV 安全）。

为证明这个定理，我们使用一种叫做**规约**（Reduction）的范式。
:::

## 3.14 规约证明范式

::: def 规约范式 The Reduction Paradigm @P85–87
**任务**：已知问题 $X$ 是困难的（即除了以可忽略概率外，不能被 PPT 算法解决），证明某个系统构造 $\Pi$ 是安全的。

**怎么证？** 证明“解决问题 $X$”可以**归约**到“攻破 $\Pi$”：换句话说，<span class="hl">如果你能高效地（以不可忽略的概率）攻破 $\Pi$，你就能高效地（以不可忽略的概率）解决 $X$。</span>

关键在于构造一个高效算法 $\mathcal A'$（我们称之为“**规约**”），它借助任何一个 $\Pi$ 的攻破者来解决 $X$。
:::

<Fig src="/img/03/p088.jpg" size="md" cap="规约证明的高层概览：规约 A′ 收到问题 X 的实例 x，把它包装成方案 Π 的实例交给 A；A 的“攻破”结果帮助 A′ 输出 x 的解" p="88–89" />

::: def 规约证明的四步 @P88–89
1. 固定某个攻击 $\Pi$ 的 PPT 算法 $\mathcal A$，记其成功概率为 $\epsilon(n)$；
2. 构造一个高效算法 $\mathcal A'$，以 $\mathcal A$ 为子程序尝试解决 $X$：
   - (a) $\mathcal A'$ **模拟** $\Pi$ 的一个实例，交给 $\mathcal A$；
   - (b) 若 $\mathcal A$ 攻破了这个 $\Pi$ 实例，这应当让 $\mathcal A'$ 能高效地解决它收到的实例 $x$，至少以**多项式倒数**的概率 $1/p(n)$；
3. 综合 2(a)(b)，$\mathcal A'$ 以概率 $\epsilon(n)/p(n)$ 解决 $X$。若 $\epsilon(n)$ 不可忽略，则 $\epsilon(n)/p(n)$ 也不可忽略。再加上 $\mathcal A$ 高效，我们就得到了一个以不可忽略概率解决 $X$ 的高效算法 $\mathcal A'$，**与初始条件矛盾**；
4. 因此可以断定：没有高效敌手 $\mathcal A$ 能以不可忽略的概率攻破 $\Pi$。
:::

::: ex [补充说明] 规约的“方向”与三个检查点
- **方向**：要证“$X$ 难 ⇒ $\Pi$ 安全”，证的是逆否命题“$\Pi$ 不安全 ⇒ $X$ 不难”。所以是**用 $\Pi$ 的攻击者去造 $X$ 的求解者**，不要反过来。
- **检查点 ①**：$\mathcal A'$ 给 $\mathcal A$ 的模拟要和真实攻击场景**分布一致**（或差别可忽略），否则 $\mathcal A$ 的成功率无从谈起。
- **检查点 ②**：$\mathcal A'$ 的成功率与 $\epsilon(n)$ 之间只差一个多项式因子（为什么 $\epsilon/p$ 不可忽略？若它可忽略，则由命题 1 第 3 条，$\epsilon = p\cdot(\epsilon/p)$ 也可忽略，矛盾）。
- **检查点 ③**：$\mathcal A'$ 自身是 PPT（多项式的封闭性）。
:::

## 3.15 构造 3.1 的安全性证明

课件给出的“证明概要”分成几步 <Src p="90–104" />，下面先按课件复述，再给出完整证明。

::: prin 定理 3.3（即定理 3.2） @P90
若 $G$ 是 PRG，则构造 3.1 是 EAV 安全的定长私钥加密方案。
:::

**课件证明概要** <Src p="90–98" />：

- 设 $\mathcal A$ 是攻击构造 3.1（记为 $\Pi$）的 PPT 算法，令 $\frac12+\epsilon(n)$ 为它在不可区分实验中的成功概率。我们要构造一个以 $\mathcal A$ 为子程序、攻击 $G$ 的敌手 $\mathcal A'$。
- **要构造的**：一个 PPT 的伪随机/真随机区分器 $\mathcal A'$，使得
$$\big\lvert\Pr[\mathcal A'(G(s))=1]-\Pr[\mathcal A'(r)=1]\big\rvert = p(n)\cdot\epsilon(n).\tag{1}$$
- **已有的**：一个 PPT 密文区分器 $\mathcal A$，满足 $\big\lvert\Pr[\mathsf{PrivK}^{\mathsf{eav}}_{\mathcal A,\Pi}=1]-\frac12\big\rvert=\epsilon(n)$；以及 $G(s)$ 和 $r$。
- **怎么造**：分别以 $k=G(s)$ 和 $k=r$ 用 $\mathcal A$ 模拟不可区分实验，把这个密文区分器当作所需的伪随机/真随机区分器；**若 $\mathcal A$ 赢了，输出 1**。
- 验证 (1)：喂入 $G(s)$ 时，$\Pr[\mathcal A'(G(s))=1]=\Pr[\mathcal A\text{ 赢 }\mathsf{PrivK}^{\mathsf{eav}}_{\mathcal A,\Pi}]=\Pr[\mathsf{PrivK}^{\mathsf{eav}}_{\mathcal A,\Pi}=1]$，已知 $\big\lvert\Pr[\mathsf{PrivK}^{\mathsf{eav}}_{\mathcal A,\Pi}=1]-\frac12\big\rvert=\epsilon(n)$ ……(2)
- 喂入 $r$ 时，记对应的加密方案为 $\Pi'$：$\Pr[\mathcal A'(r)=1]=\Pr[\mathsf{PrivK}^{\mathsf{eav}}_{\mathcal A,\Pi'}=1]$。因为 $\Pi'$ 实际上就是 OTP（完美保密），$\Pr[\mathsf{PrivK}^{\mathsf{eav}}_{\mathcal A,\Pi'}=1]=\frac12$ ……(3)
- 由 (2)(3)：$\big\lvert\Pr[\mathcal A'(G(s))=1]-\Pr[\mathcal A'(r)=1]\big\rvert=\epsilon(n)$ ……(4)。若 $\epsilon(n)$ 不可忽略，我们就找到了一个（**高效的？？？**）算法 $\mathcal A'$，以不可忽略的概率区分 PRG 输出与真随机数——根据 PRG 的定义这不可能，所以不存在以不可忽略概率攻破构造 3.1 的 $\mathcal A$。
- 还需验证 $\mathcal A'$ 是**高效**的，为此要深入规约的细节。

<span class="muted">（课件的小瑕疵：P90 把成功率写成 $\frac12+\epsilon(n)$，P91 又写成 $\lvert\Pr-\frac12\rvert=\epsilon(n)$，两处 $\epsilon$ 的定义差一个绝对值；(1) 式写的是 $p(n)\cdot\epsilon(n)$，但最终得到的 (4) 式是 $\epsilon(n)$——这里的规约是“紧”的，不损失多项式因子，(1) 只是沿用了通用范式的写法；P96 的 “$\Pr[\mathcal A'(r)]$” 漏了 “$=1$”；P91 的 “PriKeav” 应为 PrivK<sup>eav</sup>。另外，定理 3.2 与定理 3.3 是同一个定理的两个编号。）</span>

### 3.15.1 规约的细节：真实实验 vs $\mathcal A'$ 的模拟

给定 $K = G(s)$ 或 $r$，$\mathcal A'$ 以 $\mathsf{PrivK}^{\mathsf{eav}}_{\mathcal A,\Pi}$ / $\mathsf{PrivK}^{\mathsf{eav}}_{\mathcal A,\Pi'}$ 为蓝本，**模拟 $\mathcal A$ 的挑战者** <Src p="99–103" />（课件此处是左右两栏逐行对照的动画，这里重画为对照表）：

| 步骤 | 真实实验 $\mathsf{PrivK}^{\mathsf{eav}}_{\mathcal A,\Pi}(n)$ | 规约 $\mathcal A'$ 的模拟 |
|---|---|---|
| ① | 给定 $1^n$，$\mathcal A$ 输出 $m_0,m_1$（$\lvert m_0\rvert=\lvert m_1\rvert$），发给挑战者 $\mathcal C$ | 同左，但接收者从 $\mathcal C$ 换成了 $\mathcal A'$（课件在 $\mathcal C$ 上画了删除线） |
| ② | $\mathcal C$ 计算 $b\xleftarrow{\$}\{0,1\}$ 和挑战密文 $c := K\oplus m_b$，发给 $\mathcal A$ | $\mathcal A'$ 计算 $b\xleftarrow{\$}\{0,1\}$ 和 $c := K\oplus m_b$，发给 $\mathcal A$ |
| ③ | $\mathcal A$ 输出比特 $b'$ | $\mathcal A$ 输出比特 $b'$ |
| ④ | 若 $b=b'$ 则 $\mathsf{PrivK}^{\mathsf{eav}}_{\mathcal A,\Pi}(n)=1$，否则为 0 | 若 $b=b'$ 则 $\mathcal A'$ **输出 1**，否则输出 0 |

<span class="muted">（课件右栏第 ① 步写成“给定 $1^n$，$\mathcal A'$ 输出一对消息……发给挑战者 $\mathcal C$”，有误：输出消息的是 $\mathcal A$，接收者是 $\mathcal A'$；$\mathcal A'$ 自己只从外部 PRG 挑战者那里收到 $K$。左栏第 ② 步的 $K$ 在真实实验中应为 $G(k)$，$k\leftarrow\mathsf{Gen}(1^n)$。）</span>

<L03Reduction />

::: def 规约的效率 @P104
- 根据假设，“$\mathcal A$ 是攻击构造 3.1 的 PPT 算法”，所以步骤 ①+③ 是高效的，即多项式时间有界；
- 步骤 ② 要计算一个 $l(n)$ 位的串（异或），$l$ 是多项式，所以是高效的；
- 步骤 ④ 只需比较两个比特，是高效的。

因此 $\mathcal A'$ 是高效的。
:::

### 3.15.2 完整证明

**证明**（每步注明依据）。任取攻击 $\Pi$（构造 3.1）的 PPT 敌手 $\mathcal A$，定义
$$\epsilon(n) := \Pr\big[\mathsf{PrivK}^{\mathsf{eav}}_{\mathcal A,\Pi}(n)=1\big]-\frac12 .$$
只需证明 $\epsilon(n)\le\mathrm{negl}(n)$。

**① 构造区分器 $\mathcal A'$**：输入 $w\in\{0,1\}^{l(n)}$。
运行 $\mathcal A(1^n)$ 得到 $m_0,m_1\in\{0,1\}^{l(n)}$；均匀选 $b\in\{0,1\}$；令 $c:=w\oplus m_b$ 交给 $\mathcal A$，得到 $b'$；若 $b'=b$ 输出 1，否则输出 0。

**② $\mathcal A'$ 是 PPT**：运行 $\mathcal A$ 是多项式时间（假设）；选 $b$ 是 $O(1)$；异或 $l(n)$ 位是 $O(l(n))$，$l$ 是多项式；比较是 $O(1)$。多项式之和仍是多项式。

**③ 情形 $w=r$（$r$ 均匀）**：$\mathcal A$ 看到的 $c=r\oplus m_b$ 恰好是一次性密码本 $\Pi'$（$l(n)$ 位，密钥 $r$ 均匀）对 $m_b$ 的加密，$\mathcal A$ 的整个视图与 $\mathsf{PrivK}^{\mathsf{eav}}_{\mathcal A,\Pi'}(n)$ 中**同分布**，且 $\mathcal A'$ 输出 1 当且仅当 $\mathcal A$ 赢。由第 02 讲：OTP 完美保密 ⇒ 完美不可区分（对任意敌手胜率恰为 $\frac12$），故
$$\Pr_{r}[\mathcal A'(r)=1]=\Pr\big[\mathsf{PrivK}^{\mathsf{eav}}_{\mathcal A,\Pi'}(n)=1\big]=\frac12 .$$

**④ 情形 $w=G(s)$（$s\in\{0,1\}^n$ 均匀）**：$\mathcal A$ 看到的 $c=G(s)\oplus m_b$，而在真实实验中 $k\leftarrow\mathsf{Gen}(1^n)$ 也是 $\{0,1\}^n$ 上均匀的，$c=G(k)\oplus m_b$。两者同分布，于是
$$\Pr_{s}[\mathcal A'(G(s))=1]=\Pr\big[\mathsf{PrivK}^{\mathsf{eav}}_{\mathcal A,\Pi}(n)=1\big]=\frac12+\epsilon(n) .$$

**⑤ 用 PRG 的伪随机性**：$\mathcal A'$ 是 PPT 区分器（由 ②），由 PRG 定义存在可忽略函数 $\mathrm{negl}$ 使
$$
\lvert\epsilon(n)\rvert
=\Big\lvert\Big(\tfrac12+\epsilon(n)\Big)-\tfrac12\Big\rvert
=\big\lvert\Pr[\mathcal A'(G(s))=1]-\Pr[\mathcal A'(r)=1]\big\rvert
\le\mathrm{negl}(n).
$$
第一个等号是代数恒等式，第二个等号代入 ③④。

**⑥ 结论**：$\Pr[\mathsf{PrivK}^{\mathsf{eav}}_{\mathcal A,\Pi}(n)=1]=\frac12+\epsilon(n)\le\frac12+\mathrm{negl}(n)$。由于 $\mathcal A$ 是任意的 PPT 敌手，按定义 2.2，$\Pi$ 是 EAV 安全的。∎

::: exam [考点] 规约证明的答题模板
期中 Q5（证明 $F'(k,x)=F(k,x)\oplus x$ 是 PRF）用的正是同一套路，只是把 PRG 换成了 PRF（后续课程）：
1. **反设**：存在 PPT 敌手 $\mathcal A$ 以不可忽略优势攻破新构造；
2. **构造** $\mathcal B$：把收到的挑战（$w$ / 预言机）包装后喂给 $\mathcal A$，原样或稍加变换输出 $\mathcal A$ 的结果；
3. **两个世界分别算概率**：“伪随机”世界 = $\mathcal A$ 的真实攻击场景；“真随机”世界 = 某个理想对象（OTP / 真随机函数），概率可直接算出；
4. **得出矛盾**：$\mathcal B$ 的优势 = $\mathcal A$ 的优势，不可忽略，与假设矛盾；别忘了说明 $\mathcal B$ 是 PPT。
:::

- $\mathsf{PrivK}^{\mathsf{eav}}$：$\mathcal A$ 选等长 $m_0,m_1$，猜 $b$

- ⇔ $\lvert p_0-p_1\rvert\le\mathrm{negl}$ ⇔ 语义安全

- 确定性，$l(n)>n$
- 任何 PPT 区分器优势可忽略
- 值域只占 $\le 2^{n-l(n)}$，穷举可区分但要 $2^n$ 步
