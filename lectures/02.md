# 完美保密

<p class="lead">怎样的加密才算“绝对安全”？本讲先复习概率论（条件概率、全概率公式、贝叶斯定理），再站在敌手的角度推理密文泄露了什么，由此引出 Shannon 的完美保密定义及其两个等价形式（密文分布与明文无关、不可区分游戏）；然后证明一次一密是完美保密的，并看清完美保密的代价：密钥至少和消息一样多。最后用 Shannon 定理判定一个方案是否完美保密。</p>

## 2.1 来玩个游戏：“十问” <Src p="4–5" />

**规则**：最多问 10 个“是 / 否”问题，猜出老师来自哪个省份。

<Fig src="/img/02/p004.jpg" size="md" cap="中国地图（来源：chinadiscovery.com）" p="4" />

::: qa 回顾一下：是什么在引导你的猜测？你为什么会提出新的猜测？ @P5
**概率。** 你其实一直在对概率做推理：每得到一个回答，就更新“老师来自各个省份”的可能性，再挑一个最能缩小范围的新问题。
:::

::: ex [补充说明] 和加密有什么关系？
把“回答”换成“密文”：敌手看到密文后，也会像你一样更新对明文的概率估计。本讲的核心问题就是——**能不能让密文对这种推理毫无帮助**，即看到密文前后，敌手对明文的概率判断完全不变？这就是“完美保密”。
:::

::: tldr
猜测的本质是概率推理；完美保密要求密文不能改变敌手对明文的任何概率判断。
:::

## 2.2 概率论速览

### 2.2.1 什么是概率 <Src p="7–9" />

很多事件无法完全确定地预测。**概率**（<span class="en">Probability</span>）用来刻画事件发生的可能性有多大，例如（课件的玩笑）：

$$\Pr[\text{女神、男神、霸道总裁统统爱上我}] = 0.00001,\qquad \Pr[\text{你此刻正在看/听这段文字}] = 0.99999$$

<span class="muted">（概率回顾部分的材料取自 mathsisfun.com）</span>

::: def 古典概率定义 Classical Definition of Probability @P8
考虑一个**试验**（<span class="en">experiment</span>），其所有可能结果构成**样本空间**（<span class="en">sample space</span>）$\mathcal{O}$。**事件**（<span class="en">event</span>）$A$ 是若干结果的集合，即 $\mathcal{O}$ 的任一子集。定义

$$\Pr[A] = \frac{A \text{ 中包含的结果数}}{\text{所有可能结果的总数}}$$

这一定义隐含两个假设：① 样本空间**有限**；② 各结果**等可能**发生。
:::

<div class="two-col" style="display:grid;grid-template-columns:minmax(0,1fr) 260px;gap:18px;align-items:center">
<div>

**例：掷骰子** <Src p="9" />。设 $X$ 为掷出的点数，$\mathcal{O} = \{X=1, X=2, \dots, X=6\}$，则

$$\Pr[X=6] = \frac{|\{X=6\}|}{|\mathcal{O}|} = \frac16,\qquad \Pr[X\ge 5] = \frac{|\{X=5, X=6\}|}{|\mathcal{O}|} = \frac26$$

</div>
<Fig src="/img/02/p009.webp" cap="掷骰子" p="9" />
</div>

::: def 概率的统计定义 @P10
古典定义的两个假设常常不成立，人们通常改用**统计定义**：把试验重复 $n$ 次，记事件 $A$ 发生了 $n_A$ 次，称 $\frac{n_A}{n}$ 为 $A$ 的**累积相对频率** $\mathrm{CRF}(A)$，定义

$$\Pr[A] = \lim_{n\to\infty} \mathrm{CRF}(A)$$

这样的重复试验称为**伯努利试验**（<span class="en">Bernoulli experiment</span>）。现代的**公理化**概率定义由柯尔莫哥洛夫（A. N. Kolmogorov）基于测度论提出。

<span class="muted">注：课件原文拼作 “Bernouli”。严格地说，“频率趋于概率”是伯努利大数定律的结论，而不是概率的定义本身——这也是后来需要公理化定义的原因之一。</span>
:::

### 2.2.2 条件概率与独立性 <Src p="11–15" />

::: def 条件概率 Conditional Probability @P11
在事件 $B$ 发生的条件下，事件 $A$ 发生的概率为

$$\Pr[A \mid B] = \frac{\Pr[A \wedge B]}{\Pr[B]},\qquad \text{其中 } \Pr[A \wedge B] = \Pr[A \cap B] \text{ 表示 } A、B \text{ 同时发生}.$$

掷骰子的例子：

$$\Pr[X=6 \mid X\ge 5] = \frac{|\{X=6\}\cap\{X=5,X=6\}|}{|\{X=5,X=6\}|} = \frac12,\qquad \Pr[X\ge 5 \mid X=6] = \frac{|\{X=6\}\cap\{X=5,X=6\}|}{|\{X=6\}|} = 1$$

<span class="muted">注：课件这两行的分子都写成了 $|\{X=5\}\cap\{X=5,X=6\}|$，第二行的分数线也误排成了 “∥”；按定义分子应为 $|\{X=6\}\cap\{X=5,X=6\}|$（数值结果 1/2、1 不受影响）。上面已按定义写出。</span>
:::

把事件换成随机变量取值 <Src p="12–14" />：设随机变量 $X$、$Y$ 的取值空间分别为 $\mathcal{X}$、$\mathcal{Y}$，

$$\Pr[X=x \mid Y=y] = \frac{\Pr[X=x \wedge Y=y]}{\Pr[Y=y]}.$$

::: def 独立 Independence @P12–15
- $X$ 与 $Y$（相互）**独立** $\iff$ 对所有可能的 $x, y$：$\Pr[X=x \wedge Y=y] = \Pr[X=x]\cdot\Pr[Y=y]$。
  等价地，$X$ 与 $Y$ 独立 $\iff$ 对所有 $x, y$：$\Pr[X=x \mid Y=y] = \Pr[X=x]$（知道 $Y$ 不改变对 $X$ 的判断）。
- **推广到 $n$ 个变量**：$X_1,\dots,X_n$（取值空间 $\mathcal{X}_1,\dots,\mathcal{X}_n$）**相互独立** $\iff$ 对所有 $x_1\in\mathcal{X}_1,\dots,x_n\in\mathcal{X}_n$：
  $$\Pr[X_1=x_1 \wedge \cdots \wedge X_n=x_n] = \Pr[X_1=x_1]\cdots\Pr[X_n=x_n].$$
- **两两独立**（<span class="en">pairwise independent</span>）$\iff$ 对所有 $i\ne j$ 及所有 $x_i, x_j$：$\Pr[X_i=x_i \wedge X_j=x_j] = \Pr[X_i=x_i]\cdot\Pr[X_j=x_j]$。
:::

::: ex [补充说明] 留意“独立”的形式
“$\Pr[X=x \mid Y=y] = \Pr[X=x]$”——**知道 $Y$ 之后，$X$ 的分布不变**。把 $X$ 换成明文 $M$、$Y$ 换成密文 $C$，就是 2.5 节完美保密的定义。完美保密本质上就是：**明文与密文相互独立**。
:::

::: qa 能否举例：$X, Y, Z$ 相互独立，但不两两独立？ @P15
<span class="muted">（课件只提问未给答案，以下为补充说明。）</span>按课件给出的定义，**不存在**这样的例子：若对所有 $x,y,z$ 都有 $\Pr[X=x\wedge Y=y\wedge Z=z]=\Pr[X=x]\Pr[Y=y]\Pr[Z=z]$，两边对 $z$ 求和即得 $\Pr[X=x\wedge Y=y]=\Pr[X=x]\Pr[Y=y]$，其余两对同理。所以**相互独立 ⟹ 两两独立**，这道题是个“陷阱题”。
:::

::: qa 能否举例：$X, Y, Z$ 两两独立，但不相互独立？ @P15
<span class="muted">（补充说明）</span>经典例子：$X, Y$ 是独立均匀的随机比特，$Z = X \oplus Y$。

- 任意两个都独立：例如 $\Pr[X=a \wedge Z=c] = \Pr[X=a \wedge Y=a\oplus c] = \frac14 = \Pr[X=a]\Pr[Z=c]$；
- 但三者不相互独立：$\Pr[X=0\wedge Y=0\wedge Z=1] = 0 \ne \frac18$。

有意思的是，$Z = X\oplus Y$ 正是 2.6 节一次一密的形式：只看密文 $Z$，它与明文 $X$ 独立。
:::

### 2.2.3 全概率公式与贝叶斯定理 <Src p="16–19" />

::: def 全概率公式 Total Probability Formula @P16
设 $n$ 个**两两互斥**的事件 $E_1,\dots,E_n$ 构成样本空间 $\mathcal{O}$ 的一个划分，则任一事件 $A$ 的概率为

$$\Pr[A] = \sum_{i=1}^{n} \Pr[A \mid E_i]\cdot\Pr[E_i].$$
:::

<Fig src="/img/02/p016.webp" size="sm" cap="全概率公式：E₁,…,Eₙ 把样本空间划分开，A 被切成 n 块" p="16" />

::: def 贝叶斯定理 Bayes' Theorem @P17
对两个事件 $A$、$B$：

$$\Pr[A \mid B] = \frac{\Pr[A]\cdot\Pr[B \mid A]}{\Pr[B]}.$$

它帮助我们在已知一个事件发生时，推理另一个事件发生的可能性。对随机变量 <Src p="19" />：

$$\Pr[X=x \mid Y=y] = \frac{\Pr[X=x]\cdot\Pr[Y=y \mid X=x]}{\Pr[Y=y]}.$$
:::

::: qa 早上多云，要不要去野餐？已知：50% 的雨天早上是多云的；约 40% 的日子早上多云；这个月很干燥（30 天里只有 3 天下雨，即 10%）。求 $\Pr[\text{雨}\mid\text{云}]$。 @P18
<span class="muted">（课件只提问，以下计算为补充说明。）</span>由贝叶斯定理：

$$\Pr[\text{雨}\mid\text{云}] = \frac{\Pr[\text{雨}]\cdot\Pr[\text{云}\mid\text{雨}]}{\Pr[\text{云}]} = \frac{0.1\times 0.5}{0.4} = 0.125.$$

只有 12.5% 的可能下雨——去吧！注意“看到云”把下雨的概率从**先验** 10% 更新到了**后验** 12.5%：观测改变了判断。
:::

::: tldr
记住三件工具：条件概率 $\Pr[A\mid B]=\Pr[A\wedge B]/\Pr[B]$、全概率公式（分母）、贝叶斯定理（先验 → 后验）。后面每个证明都只用它们。
:::

## 2.3 加密方案的定义

### 2.3.1 “不可破译密码”的开端 <Src p="22–23" />

<div class="two-col" style="display:grid;grid-template-columns:minmax(0,1fr) 170px;gap:18px;align-items:center">
<div>

- 1948 年，Shannon 发表里程碑论文 *A Mathematical Theory of Communication*，奠定了**信息论**；
- 1949 年，Shannon 发表 *Communication Theory of Secrecy Systems*（CTSS）；
- 在 CTSS 中，Shannon 证明了“不可破译密码”的判定准则，并证明了 **Vernam 密码**（即一次一密）是不可破译的。

</div>
<Fig src="/img/02/p022.jpg" cap="Claude E. Shannon（1916–2001），信息论之父（照片来自 Wikipedia）" p="22" />
</div>

在 CTSS 中，Shannon 这样定义一个保密通信系统（密码系统）：

<Fig src="/img/02/p023.jpg" size="md" cap="Shannon 论文中的密码系统：消息源 M → 加密器 T_K → 密文 E → 解密器 T_K⁻¹ → M；密钥源经安全信道把 K 同时交给双方，敌方密码分析员只能截获 E" p="23" />

### 2.3.2 形式化定义

::: def 加密方案 Encryption Scheme @P24–27
一个加密方案 $\Pi$（也称 **密码** <span class="en">cipher</span> 或 **密码体制** <span class="en">cryptosystem</span>）由三个算法 $\mathsf{Gen}$、$\mathsf{Enc}$、$\mathsf{Dec}$ 以及一个**有限**的消息空间 $\mathcal{M}$（$|\mathcal{M}|>1$）组成：

- **$\mathsf{Gen}$**：**概率**算法，按某个分布（通常是均匀分布）从有限的密钥空间 $\mathcal{K}$ 中输出一把密钥 $k$，记作 $k \leftarrow \mathsf{Gen}$。
- **$\mathsf{Enc}$**：输入密钥 $k\in\mathcal{K}$ 和消息 $m\in\mathcal{M}$，输出密文 $c$。可以是概率的 $c \leftarrow \mathsf{Enc}_k(m)$，也可以是确定的 $c := \mathsf{Enc}_k(m)$。
- **$\mathsf{Dec}$**：**确定性**算法，输入密文 $c$（来自全体密文的集合 $\mathcal{C}$）和密钥 $k\in\mathcal{K}$，输出消息 $m := \mathsf{Dec}_k(c)$。

<span class="muted">脚注：这里定义的其实是**对称**（私钥）加密方案——加解密用同一把密钥。</span>
:::

::: ex [例 1] 移位密码 Π<sub>shft1</sub> @P28
- $\mathcal{M} = \{0,\dots,25\}$（或 $\{a,\dots,z\}$），即消息只有**一个字母**；
- $\mathsf{Gen}$：$k \xleftarrow{\text{u}} \{0,\dots,25\}$（均匀选取；课件在箭头上方标一个美元符号表示均匀随机，下同）；
- $\mathsf{Enc}$：$C = M + k \bmod 26$；
- $\mathsf{Dec}$：$M := C - k \bmod 26$。
:::

::: ex [例 2] 移位密码 Π<sub>shft2</sub> @P29
- $\mathcal{M} = \{0,\dots,25\}^3$（或 $\{a,\dots,z\}^3$），即消息是**三个字母**；
- $\mathsf{Gen}$：$k \xleftarrow{\text{u}} \{0,\dots,25\}$——仍然只有一个移位量；
- $\mathsf{Enc}$：对 $M = m_1\|m_2\|m_3$，$C = (m_1+k \bmod 26)\,\|\,(m_2+k \bmod 26)\,\|\,(m_3+k \bmod 26)$；
- $\mathsf{Dec}$：对 $c = c_1\|c_2\|c_3$，$M := (c_1-k \bmod 26)\,\|\,(c_2-k \bmod 26)\,\|\,(c_3-k \bmod 26)$。
:::

::: tldr
加密方案 = (Gen, Enc, Dec) + 消息空间；Gen 必须随机，Dec 必须确定。Π<sub>shft1</sub> 与 Π<sub>shft2</sub> 的唯一区别是：一个移位量加密一个字母，还是三个字母。
:::

## 2.4 站在敌手的角度 <Src p="31–38" />

::: qa 设消息 $M$ 服从分布 $\Pr[M=\texttt{ann}]=0.6$、$\Pr[M=\texttt{bob}]=0.4$，用 Π<sub>shft2</sub> 加密后敌手看到密文 <code>DQQ</code>。敌手能知道 $M$ 吗？ @P31–32
**很遗憾，能。** 敌手可以确定 $M = \texttt{ann}$。:(
:::

聪明的敌手是这样推理的 <Src p="33" />。先用**全概率公式**算出看到 `DQQ` 的概率：

$$
\begin{aligned}
\Pr[C=\texttt{DQQ}]
&= \Pr[M=\texttt{ann}]\cdot\Pr[C=\texttt{DQQ}\mid M=\texttt{ann}] + \Pr[M=\texttt{bob}]\cdot\Pr[C=\texttt{DQQ}\mid M=\texttt{bob}]\\
&= \Pr[M=\texttt{ann}]\cdot\Pr[K=3] + \Pr[M=\texttt{bob}]\cdot\Pr[K=\varnothing]\\
&= 0.6\cdot\tfrac{1}{26} + 0.4\cdot 0 = \tfrac{3}{130}.
\end{aligned}
$$

依据：`ann` 移 3 位恰好是 `DQQ`（a→D，n→Q），所以只有 $K=3$ 一把密钥；而 `bob` 的首尾字母相同、`DQQ` 的首尾字母不同，**没有任何**密钥能把 `bob` 加密成 `DQQ`。<span class="muted">（课件用 $\Pr[K=\varnothing]$ 表示“不存在这样的密钥”，即概率为 0，这是非标准写法。）</span>

再用**贝叶斯定理**：

$$\Pr[M=\texttt{ann}\mid C=\texttt{DQQ}] = \frac{\Pr[M=\texttt{ann}]\cdot\Pr[C=\texttt{DQQ}\mid M=\texttt{ann}]}{\Pr[C=\texttt{DQQ}]} = \frac{0.6\cdot\frac{1}{26}}{\frac{3}{130}} = 1.$$

::: ex [补充说明] 泄露在哪？
Π<sub>shft2</sub> 用同一个 $k$ 移动三个字母，**字母之间的差**（$m_2-m_1$、$m_3-m_2$）原封不动留在密文里。`ann` 的模式是“xyy”，`bob` 是“xyx”——看一眼密文的模式就分出来了。这和上一讲单表替换“保留频率”是同一类毛病。
:::

同样的分析放到 Π<sub>shft1</sub> 上：

::: qa Q1：Π<sub>shft1</sub> 下，设 $\Pr[M=b]=0.6$、$\Pr[M=g]=0.4$，密文为 $Z$ 的概率是多少？ @P34–36
b = 1、g = 6、Z = 25，所以 b 需要 $K=24$，g 需要 $K=19$，各只有一把密钥：

$$
\begin{aligned}
\Pr[C=Z] &= \Pr[M=b \wedge K=24] + \Pr[M=g \wedge K=19]\\
&= \Pr[M=b]\cdot\Pr[K=24] + \Pr[M=g]\cdot\Pr[K=19] \qquad(\text{M 与 K 独立})\\
&= 0.6\cdot\tfrac{1}{26} + 0.4\cdot\tfrac{1}{26} = \tfrac{1}{26}.
\end{aligned}
$$
:::

::: qa Q2：按上述分布抽取 $M$、加密后得到密文 $Z$。$M=b$ 的概率是多少？ @P37–38
由贝叶斯定理：

$$\Pr[M=b\mid C=Z] = \frac{\Pr[M=b]\cdot\Pr[C=Z\mid M=b]}{\Pr[C=Z]} = \frac{\Pr[M=b]\cdot\Pr[K=24]}{\Pr[C=Z]} = \frac{\Pr[M=b]\cdot\frac{1}{26}}{\frac{1}{26}} = \Pr[M=b] = 0.6.$$

看到密文前后，$M=b$ 的概率**都是 0.6**——密文没有给敌手任何新信息。
:::

自己动手：换方案、改先验、换密文，看后验是否等于先验。

<L02Posterior />

::: tldr
敌手用“全概率公式 + 贝叶斯定理”从密文更新对明文的判断。Π<sub>shft2</sub> 下后验从 0.6 跳到 1（完全泄露）；Π<sub>shft1</sub> 下后验恒等于先验。
:::

## 2.5 完美保密的定义

::: def 定义 3.1 完美保密的加密 Perfectly Secret Encryption @P40
定义在消息空间 $\mathcal{M}$ 上的加密方案 $(\mathsf{Gen},\mathsf{Enc},\mathsf{Dec})$ 是**完美保密**的，如果对 $\mathcal{M}$ 上的**每一个**概率分布，

$$\Pr[M=m \mid C=c] = \Pr[M=m]$$

对每个 $m\in\mathcal{M}$ 和每个满足 $\Pr[C=c]>0$ 的 $c\in\mathcal{C}$ 都成立。
:::

::: ex [补充说明] 读懂定义里的三个“每”
- **每一个分布**：敌手可能事先掌握任何先验知识（例如“这封邮件 90% 是 yes”），定义不能只对均匀分布成立；
- **每个 $m$、每个 $c$**：不能只是“平均来说”不泄露，而是任何一条密文都不泄露；
- **$\Pr[C=c]>0$**：只是为了让条件概率的分母有意义——不可能出现的密文无所谓。

另外，这里的概率空间同时包含 $M$ 的分布和 $\mathsf{Gen}$（以及概率性 $\mathsf{Enc}$）的随机性，且 $M$ 与 $K$ **相互独立**——后面所有证明都会用到这一点。
:::

由定义立刻可知 <Src p="41" />：**Π<sub>shft2</sub> 不是完美保密的**，因为

$$\Pr[M=\texttt{ann}\mid C=\texttt{DQQ}] = 1 \ne \Pr[M=\texttt{ann}] = 0.6.$$

（要否定完美保密，只需找到**一个**分布、**一对** $m, c$ 使等式不成立。）

::: qa Π<sub>shft1</sub> 是完美保密的吗？ @P41–43
**大概是**，但我们还需要证明——2.4 节只验证了一个特定分布和一个特定密文，而定义要求“对每个分布、每对 $m, c$”。
:::

::: def 定理 3.2 Π<sub>shft1</sub> 是完美保密的加密方案 @P44–48
**证明**：对任意 $m\in\mathcal{M}=\{0,\dots,25\}$、任意 $c\in\mathcal{C}$ 以及 $\mathcal{M}$ 上任意分布，

$$
\begin{aligned}
\Pr[M=m\mid C=c]
&= \frac{\Pr[M=m\wedge C=c]}{\Pr[C=c]} &&\text{①}\\[2pt]
&= \frac{\Pr[M=m]\cdot\Pr[C=c\mid M=m]}{\sum_{m'\in\mathcal{M}} \Pr[M=m']\cdot\Pr[C=c\mid M=m']} &&\text{②}\\[2pt]
&= \frac{\Pr[M=m]\cdot\Pr[k\equiv c-m \pmod{26}]}{\sum_{m'\in\mathcal{M}} \Pr[M=m']\cdot\Pr[k\equiv c-m' \pmod{26}]} &&\text{③}\\[2pt]
&= \frac{\Pr[M=m]\cdot\frac{1}{26}}{\frac{1}{26}\sum_{m'\in\mathcal{M}} \Pr[M=m']} &&\text{④}\\[2pt]
&= \Pr[M=m]. &&\text{⑤}
\end{aligned}
$$

逐步依据：
① 条件概率的定义；
② 分子用乘法公式（即贝叶斯定理），分母用全概率公式（按 $M$ 的取值 $0,\dots,25$ 划分，课件写作 $\Pr[M=0\wedge C=c]+\cdots+\Pr[M=25\wedge C=c]$）；
③ 已知 $M=m$ 时，$C=c \iff k \equiv c-m \pmod{26}$，又因 $M$ 与 $k$ 独立，条件概率就等于密钥事件本身的概率；
④ 密钥均匀，每项 $\Pr[k=\cdot\,]=\frac{1}{26}$，分母提出公因子；
⑤ 约去 $\frac1{26}$，并用归一性 $\sum_{m'}\Pr[M=m']=1$。 ∎
:::

### 2.5.1 等价定义：密文分布与明文无关 <Src p="49–59" />

::: def 引理 3.3 完美保密的等价表述 @P49
加密方案 $(\mathsf{Gen},\mathsf{Enc},\mathsf{Dec})$ 是完美保密的，**当且仅当**对每个 $m, m'\in\mathcal{M}$ 和每个 $c\in\mathcal{C}$：

$$\Pr[C=c\mid M=m] = \Pr[C=c\mid M=m'].$$

含义：**密文的概率分布与明文无关**。换句话说，“不可能区分 $m_0$ 的密文和 $m_1$ 的密文”。
:::

::: def 引理 3.3 的证明 @P50–59
**（⇐）** 设 $\Pr[C=c\mid M=m]=\Pr[C=c\mid M=m']$ 对所有 $m, m'$ 成立，记这个公共值为 $p$（它只依赖于 $c$）。对任意分布、任意 $m$ 和 $\Pr[C=c]>0$ 的 $c$：

$$
\Pr[M=m\mid C=c]
= \frac{\Pr[M=m\wedge C=c]}{\Pr[C=c]}
= \frac{\Pr[M=m]\cdot\Pr[C=c\mid M=m]}{\sum_{m'\in\mathcal{M}}\Pr[M=m']\cdot\Pr[C=c\mid M=m']}
= \frac{\Pr[M=m]\cdot p}{p\cdot\sum_{m'\in\mathcal{M}}\Pr[M=m']}
= \Pr[M=m].
$$

依据：条件概率定义 → 分子乘法公式、分母全概率公式 → 代入公共值 $p$ → 约去 $p$（$\Pr[C=c]>0$ 保证 $p>0$）并用归一性。

**（⇒）** 设方案完美保密。$m'=m$ 时结论平凡，下面只考虑 $m'\ne m$。对每个这样的 $m'$，**构造**一个分布：$\Pr[M=m]=0.7$、$\Pr[M=m']=0.3$（其余消息概率为 0）。记

$$a=\Pr[C=c\mid M=m],\qquad b=\Pr[C=c\mid M=m'].$$

由完美保密的定义（它对**任意**分布成立，当然也对这个分布成立）：

$$
0.7 = \Pr[M=m] = \Pr[M=m\mid C=c]
= \frac{\Pr[M=m]\cdot a}{\Pr[M=m']\cdot b + \Pr[M=m]\cdot a}
= \frac{0.7\,a}{0.3\,b+0.7\,a}.
$$

两边除以 0.7 再去分母：$0.3\,b+0.7\,a = a$，即 $0.3\,b = 0.3\,a$，故 $a=b$，也就是 $\Pr[C=c\mid M=m]=\Pr[C=c\mid M=m']$。 ∎

<span class="muted">注：（⇒）中用到了 $\Pr[C=c]>0$ 才能写出条件概率。若在这个构造分布下 $\Pr[C=c]=0$，则 $0.3b+0.7a=0$，即 $a=b=0$，结论同样成立——课件对这一情形未单独说明。</span>
:::

### 2.5.2 完美不可区分：基于游戏的定义 <Src p="60–68" />

现在给出完美保密的一个**基于游戏**的定义。对加密方案 $\Pi=(\mathsf{Gen},\mathsf{Enc},\mathsf{Dec})$ 和消息空间 $\mathcal{M}$，定义敌手 $\mathcal{A}$ 与**挑战者**（<span class="en">challenger</span>）之间的敌手不可区分试验 $\mathsf{PrivK}^{\mathsf{eav}}_{\mathcal{A},\Pi}$（eav = eavesdropper，窃听者）：

::: def 不可区分试验 PrivK<sup>eav</sup><sub>𝒜,Π</sub> @P60–65
1. 敌手 $\mathcal{A}$ 选出一对消息 $m_0, m_1\in\mathcal{M}$，发给挑战者；
2. 挑战者运行 $\mathsf{Gen}$ 得到密钥 $k$，均匀选取比特 $b\in\{0,1\}$，加密 $m_b$ 得到**挑战密文** $c\leftarrow\mathsf{Enc}_k(m_b)$；
3. 挑战者把 $c$ 发给敌手；
4. 敌手根据 $c$ 猜测 $b$ 的值，输出 $b'$ 作为回答；
5. 若 $b'=b$，试验输出 1，记作 $\mathsf{PrivK}^{\mathsf{eav}}_{\mathcal{A},\Pi}=1$（$\mathcal{A}$ 成功）；否则输出 0。
:::

::: def 定义 3.4 完美（敌手）不可区分 Perfect Adversarial Indistinguishability @P66–67
加密方案 $\Pi=(\mathsf{Gen},\mathsf{Enc},\mathsf{Dec})$ 是**完美不可区分**的，如果对**每一个**敌手 $\mathcal{A}$ 都有

$$\Pr\bigl[\mathsf{PrivK}^{\mathsf{eav}}_{\mathcal{A},\Pi}=1\bigr] = \frac12.$$

含义：任何敌手在游戏中都**不比随机瞎猜更好，也不更差**。
:::

::: ex [补充说明] 为什么“也不更差”？
如果某个敌手的成功率是 $0.3 < \frac12$，把它的输出取反就得到成功率 $0.7$ 的敌手。所以“恰好等于 1/2”和“不超过 1/2”说的是同一件事。
:::

::: def 引理 3.5 完美保密 ⟺ 完美不可区分 @P68
加密方案 $\Pi$ 是完美保密的，当且仅当它是完美不可区分的。
:::

::: def 引理 3.5 的证明（补充说明：课件未给出证明） @P68
固定敌手选的 $m_0, m_1$，记 $p_0(c)=\Pr[C=c\mid M=m_0]$，$p_1(c)=\Pr[C=c\mid M=m_1]$。

**第 1 步：给定 $c$ 时的最佳猜法。** 因 $b$ 均匀，由贝叶斯定理

$$\Pr[b=0\mid C=c]=\frac{p_0(c)}{p_0(c)+p_1(c)},\qquad \Pr[b=1\mid C=c]=\frac{p_1(c)}{p_0(c)+p_1(c)},$$

所以任何敌手看到 $c$ 后猜对的概率不超过 $\dfrac{\max(p_0(c),p_1(c))}{p_0(c)+p_1(c)}$。

**第 2 步：对 $c$ 加权求和。** 由全概率公式 $\Pr[C=c]=\frac{p_0(c)+p_1(c)}{2}$，于是

$$\Pr\bigl[\mathsf{PrivK}^{\mathsf{eav}}_{\mathcal{A},\Pi}=1\bigr] \le \frac12\sum_c \max\bigl(p_0(c),p_1(c)\bigr) = \frac12+\frac14\sum_c\bigl|p_0(c)-p_1(c)\bigr|,$$

其中等号用了恒等式 $\max(a,b)=\frac{a+b}{2}+\frac{|a-b|}{2}$ 与 $\sum_c\bigl(p_0(c)+p_1(c)\bigr)=2$。“看到 $c$ 就输出后验较大者”的敌手使不等式取等号。

**（⇒）** 若 $\Pi$ 完美保密，由引理 3.3，$p_0(c)=p_1(c)$ 对每个 $c$ 成立，右端 $=\frac12$，即任何敌手成功率 $\le\frac12$；若某敌手 $<\frac12$，把输出取反就得到 $>\frac12$ 的敌手，矛盾。故任何敌手成功率恰为 $\frac12$。

**（⇐）** 若 $\Pi$ 完美不可区分，则对**任意** $m_0,m_1$，上面的最优敌手成功率也必须是 $\frac12$，于是 $\sum_c|p_0(c)-p_1(c)|=0$，即 $p_0\equiv p_1$；由引理 3.3 得 $\Pi$ 完美保密。 ∎

枢纽：$\sum_c\max(p_0(c),p_1(c))=1 \iff p_0\equiv p_1$，它同时给出两个方向。上面交互演示里的“理论最优胜率”就是这条公式。
:::

### 2.5.3 例：维吉尼亚密码不是完美不可区分的 <Src p="69–77" />

::: ex [例] 周期随机的维吉尼亚密码 @P69–71
设 $\Pi$ 为消息空间是**两字符串**的维吉尼亚密码，周期 $t$ 在 $\{1,2\}$ 中均匀选取（$t=1$：两个字符用同一个移位；$t=2$：两个字符各自独立均匀移位）。我们断言 $\Pi$ **不是**完美不可区分的。

为证明这一点，构造一个敌手 $\mathcal{A}$，使 $\Pr[\mathsf{PrivK}^{\mathsf{eav}}_{\mathcal{A},\Pi}=1]>\frac12$：

1. 选择 $m_0=\texttt{aa}$、$m_1=\texttt{ab}$；
2. 收到挑战密文 $c=c_1c_2$ 后，若 $c_1=c_2$ 输出 $0$，否则输出 $1$。

那么 $\Pr[\mathsf{PrivK}^{\mathsf{eav}}_{\mathcal{A},\Pi}=1]$ 等于多少？
:::

::: def 计算 @P72–77
按 $b$ 的取值用全概率公式（$b$ 均匀）：

$$
\begin{aligned}
\Pr\bigl[\mathsf{PrivK}^{\mathsf{eav}}_{\mathcal{A},\Pi}=1\bigr]
&= 0.5\Pr\bigl[\mathsf{PrivK}^{\mathsf{eav}}_{\mathcal{A},\Pi}=1\mid b=0\bigr] + 0.5\Pr\bigl[\mathsf{PrivK}^{\mathsf{eav}}_{\mathcal{A},\Pi}=1\mid b=1\bigr]\\
&= 0.5\Pr[\mathcal{A}\text{ 输出 }0\mid b=0] + 0.5\Pr[\mathcal{A}\text{ 输出 }1\mid b=1].
\end{aligned}
$$

其中

$$\Pr[\mathcal{A}\text{ 输出 }0\mid b=0] = \frac12+\frac12\cdot\frac1{26},\qquad \Pr[\mathcal{A}\text{ 输出 }1\mid b=1] = 1-\Pr[\mathcal{A}\text{ 输出 }0\mid b=1] = 1-\frac12\cdot\frac1{26}.$$

依据：$b=0$（加密 `aa`）时，$t=1$（概率 $\frac12$）必有 $c_1=c_2$；$t=2$ 时两个移位独立均匀，恰好相等的概率为 $\frac1{26}$。$b=1$（加密 `ab`）时，$t=1$ 必有 $c_1\ne c_2$；只有 $t=2$ 且第二个移位比第一个恰好小 1（概率 $\frac12\cdot\frac1{26}$）才会 $c_1=c_2$。于是

$$\Pr\bigl[\mathsf{PrivK}^{\mathsf{eav}}_{\mathcal{A},\Pi}=1\bigr] = \frac12\Bigl(\frac12+\frac12\cdot\frac1{26}+1-\frac12\cdot\frac1{26}\Bigr) = 0.75 > \frac12.$$

因此 $\Pi$ 不是完美不可区分的；由引理 3.5，它也不是完美保密的。 ∎
:::

::: tldr
完美保密有三种等价说法：后验 = 先验（定义 3.1）⟺ 密文分布与明文无关（引理 3.3）⟺ 任何敌手在 PrivK<sup>eav</sup> 中胜率恰为 1/2（引理 3.5）。证“是”要对所有分布/敌手论证，证“不是”只需一个反例。
:::

## 2.6 一次一密（Vernam 密码） <Src p="79–91" />

::: def 一次一密 The One-Time Pad @P79
记 $a\oplus b$ 为两个二进制串 $a, b$ 的**按位异或**（XOR）。一次一密如下：

1. 固定整数 $l>0$，$\mathcal{M}=\mathcal{K}=\mathcal{C}=\{0,1\}^l$；
2. $\mathsf{Gen}$：$K\xleftarrow{\text{u}}\mathcal{K}$，即对每个 $k\in\mathcal{K}$，$\Pr[K=k]=1/2^l$；
3. $\mathsf{Enc}_K(M)$：$C := M\oplus K$；
4. $\mathsf{Dec}_K(C)$：$M := C\oplus K$。

**正确性**：$C\oplus K = (M\oplus K)\oplus K = M\oplus(K\oplus K) = M$（异或满足结合律，且 $K\oplus K=0^l$）。
**保密性**：？——见定理 4.1。
:::

::: def 定理 4.1 一次一密是完美保密的加密方案 @P80–85
**证明**：固定 $\mathcal{M}$ 上任意输入分布，对每个可能的 $m$ 和 $c$，

$$
\begin{aligned}
\Pr[M=m\mid C=c]
&= \Pr[M=m, C=c]\,/\,\Pr[C=c] &&\text{①}\\
&= \Pr[K=m\oplus c]\cdot\Pr[M=m]\;\Big/\;\sum_{m'\in\mathcal{M}}\bigl(\Pr[M=m']\cdot\Pr[C=c\mid M=m']\bigr) &&\text{②}\\
&= \Pr[K=m\oplus c]\cdot\Pr[M=m]\;\Big/\;\sum_{m'\in\mathcal{M}}\bigl(\Pr[M=m']\cdot\Pr[K=m'\oplus c]\bigr) &&\text{③}\\
&= 2^{-l}\Pr[M=m]\;\Big/\;\Bigl(2^{-l}\sum_{m'\in\mathcal{M}}\Pr[M=m']\Bigr) &&\text{④}\\
&= 2^{-l}\Pr[M=m]\,/\,2^{-l} = \Pr[M=m]. &&\text{⑤}
\end{aligned}
$$

逐步依据：
① 条件概率定义；
② 分子：$M=m \wedge C=c \iff M=m \wedge K=m\oplus c$，再用 $M$ 与 $K$ 独立拆成乘积；分母：全概率公式；
③ 已知 $M=m'$ 时 $C=c\iff K=m'\oplus c$，同样用独立性；
④ 密钥均匀，每把密钥的概率都是 $2^{-l}$；
⑤ 归一性 $\sum_{m'}\Pr[M=m']=1$，约去 $2^{-l}$。 ∎
:::

### 2.6.1 一次一密的局限 <Src p="86–91" />

完美保密听起来很完美，但有什么缺点？

1. **密钥必须和消息一样长。**
   $M = \texttt{011100001100011100001101010100000000000011001}\dots$
   $K = \texttt{100011100001100011100001101010100000000000011}\dots$
2. **同一把密钥只能用一次才安全。**
   $C_1=M_1\oplus K,\ C_2=M_2\oplus K \;\Rightarrow\; C_1\oplus C_2 = M_1\oplus M_2$——密钥被消掉，泄露两条明文的异或。
3. **只能抵抗唯密文攻击。**
   已知明文 $M=101$ 与密文 $\mathsf{Enc}_K(M)=111$ 就能算出 $K=M\oplus C=010$。

::: ex [补充说明] 局限 2、3 与定义并不矛盾
定义 3.1 和 PrivK<sup>eav</sup> 刻画的都是“敌手只看到**一条**密文”的窃听者。一旦同一把密钥加密了两条消息，或敌手拿到了明文/密文对，就超出了这个威胁模型——完美保密本来就没承诺这些。后续课程会定义更强的安全概念（如 CPA 安全）。
:::

::: exam [考点] 2025 期中 Q1(2)：举一个完美保密加密算法的例子；为什么实际生活中通常不用它？
**例子**：一次一密——密钥长度 = 明文长度；密钥真随机且只能用一次；按位异或加密。
**不常用的原因**：
- 密钥管理困难：每次通信都要共享与消息等长的随机密钥，且不能重用；
- 密钥分发问题：安全传送这么大的密钥本身就需要安全信道；
- 存储与带宽开销大：传输、存储密钥成本高。
:::

::: tldr
OTP：$C=M\oplus K$，密钥均匀且与消息等长 → 完美保密。代价：密钥和消息一样长、只能用一次、只防唯密文攻击。
:::

## 2.7 完美保密的局限：|𝒦| ≥ |ℳ| <Src p="93–94" />

一次一密的“密钥和消息一样长”不是偶然——**任何**完美保密的方案都逃不掉。

::: def 定理 5.1 完美保密的密钥空间下界 @P93–94
设 $(\mathsf{Gen},\mathsf{Enc},\mathsf{Dec})$ 是消息空间 $\mathcal{M}$ 上的完美保密加密方案，$\mathcal{K}$ 为 $\mathsf{Gen}$ 所确定的密钥空间，则

$$|\mathcal{K}|\ \ge\ |\mathcal{M}|.$$

**证明**：取 $\mathcal{M}$ 上的**均匀分布**作为输入。必然存在某个 $c\in\mathcal{C}$ 使 $\Pr[C=c]>0$。由完美保密的定义，对每个 $m\in\mathcal{M}$，

$$\Pr[M=m\mid C=c] = \Pr[M=m] = \frac{1}{|\mathcal{M}|} > 0,$$

这意味着对每个 $m$，至少存在一把密钥 $k$ 使 $\mathsf{Dec}_k(c)=m$。因此 $\mathcal{K}$ 中至少有 $|\mathcal{M}|$ 把**不同**的密钥，每个不同的 $m$ 对应一把。所以 $|\mathcal{K}|\ge|\mathcal{M}|$。 ∎

逐步依据：
- 完美保密对**任意**分布成立，所以可以挑最方便的均匀分布；
- 选 $\Pr[C=c]>0$ 的 $c$，保证条件概率有定义；
- 后验 $>0$ 说明“$M=m$ 且 $C=c$”可能发生，即存在 $k$ 使 $\mathsf{Enc}_k(m)$ 输出 $c$，由正确性 $\mathsf{Dec}_k(c)=m$；
- 因 $\mathsf{Dec}$ 是**确定性**算法，一把 $k$ 只能把 $c$ 解成一个消息，所以不同的 $m$ 对应的密钥两两不同（$m\mapsto k$ 是单射）。

<span class="muted">注：课件证明中“因此至少有 |ℳ| 把不同密钥”这一步隐含用到了 Dec 的确定性，上面已补出。</span>
:::

取到等号的例子：一次一密（$|\mathcal{K}|=|\mathcal{M}|=2^l$）、单字母的 Π<sub>shft1</sub>（$|\mathcal{K}|=|\mathcal{M}|=26$）。反过来，Π<sub>shft2</sub> 只有 26 把密钥却有 $26^3$ 条消息——由定理 5.1，它**不可能**完美保密，这与 2.5 节的结论一致。<span class="muted">（补充说明）</span>

<L02KeyCount />

::: tldr
完美保密 ⟹ $|\mathcal{K}|\ge|\mathcal{M}|$：固定一条密文，每把密钥只能解出一条消息，而每条消息都必须“有可能”。密钥短于消息的方案一定不是完美保密的。
:::

## 2.8 Shannon 定理 <Src p="96" />

::: prin 定理 6.1（Shannon 定理） @P96
设 $(\mathsf{Gen},\mathsf{Enc},\mathsf{Dec})$ 是消息空间 $\mathcal{M}$ 上的加密方案，且 $|\mathcal{M}|=|\mathcal{C}|=|\mathcal{K}|$。该方案是完美保密的，**当且仅当**：

1. $\mathsf{Gen}$ 以相等的概率 $1/|\mathcal{K}|$ 选取每一把密钥 $k\in\mathcal{K}$；
2. 对每个 $m\in\mathcal{M}$ 和每个 $c\in\mathcal{C}$，**恰好存在唯一一把**密钥 $k\in\mathcal{K}$ 使 $\mathsf{Enc}_k(m)$ 输出 $c$。

- 只适用于 $|\mathcal{M}|=|\mathcal{K}|=|\mathcal{C}|$ 的情形；
- 用途：判定一个给定方案是否完美保密。

<span class="muted">注：课件原文为 “there exists a single key”，应理解为“存在**唯一**的密钥”（unique）。</span>
:::

::: ex [应用] 用 Shannon 定理重新看前面的方案（补充说明）
- **一次一密**：$|\mathcal{M}|=|\mathcal{K}|=|\mathcal{C}|=2^l$；密钥均匀 ✓；对任意 $m, c$，唯一的密钥是 $k=m\oplus c$ ✓ ⟹ 完美保密。
- **Π<sub>shft1</sub>**：三者都是 26；密钥均匀 ✓；唯一的密钥是 $k=c-m \bmod 26$ ✓ ⟹ 完美保密（与定理 3.2 一致）。
- **密钥不均匀的 Π<sub>shft1</sub>**：条件 1 不满足 ⟹ 不是完美保密（可在 2.4 节的计算器里选“密钥不均匀”验证）。
:::

::: def 定理 6.1 的证明（补充说明：课件未给出，参见 Katz & Lindell 第 2 章） @P96
下面假设 $\mathsf{Enc}$ 是确定性的，记 $\mathcal{C}$ 为所有可能出现的密文。

**（⇐）** 对任意 $m, c$，设 $k_{m,c}$ 是条件 2 给出的唯一密钥，则 $\Pr[C=c\mid M=m]=\Pr[K=k_{m,c}]=\frac1{|\mathcal{K}|}$（条件 1）。这个值与 $m$ 无关，由引理 3.3，方案完美保密。

**（⇒）** 设方案完美保密。
1. *每个 $(m,c)$ 至少有一把密钥。* 任取 $c\in\mathcal{C}$，它总能由某个 $m^*$ 加密得到，即 $\Pr[C=c\mid M=m^*]>0$；由引理 3.3，对**每个** $m$ 都有 $\Pr[C=c\mid M=m]>0$，即存在 $k$ 使 $\mathsf{Enc}_k(m)=c$。
2. *恰好一把。* 固定 $m$，映射 $k\mapsto\mathsf{Enc}_k(m)$ 由第 1 步是从 $\mathcal{K}$ 到 $\mathcal{C}$ 的**满射**；又 $|\mathcal{K}|=|\mathcal{C}|$，所以它是双射，即每个 $c$ 恰有一把 $k$。条件 2 成立。
3. *密钥均匀。* 固定 $c$，记 $k_m$ 为把 $m$ 加密成 $c$ 的唯一密钥。取 $\mathcal{M}$ 上均匀分布，由贝叶斯定理与完美保密：
   $$\frac1{|\mathcal{M}|} = \Pr[M=m\mid C=c] = \frac{\Pr[C=c\mid M=m]\Pr[M=m]}{\Pr[C=c]} = \frac{\Pr[K=k_m]\cdot\frac1{|\mathcal{M}|}}{\Pr[C=c]},$$
   故 $\Pr[K=k_m]=\Pr[C=c]$ 对所有 $m$ 相同。不同的 $m$ 对应的 $k_m$ 两两不同（一把密钥只能把 $c$ 解成一个消息），且 $|\mathcal{M}|=|\mathcal{K}|$，所以 $\{k_m\}$ 恰好就是整个 $\mathcal{K}$——每把密钥概率相同，都等于 $\frac1{|\mathcal{K}|}$。条件 1 成立。 ∎
:::

<L02ShannonCheck />

::: tldr
当 $|\mathcal{M}|=|\mathcal{K}|=|\mathcal{C}|$ 时：完美保密 ⟺ 密钥均匀 + 每对 $(m,c)$ 恰有一把密钥（加密表是“拉丁方”）。
:::

## ★ 本讲速记

:::: recap
::: card 概率工具
- 条件概率 $\Pr[A\mid B]=\Pr[A\wedge B]/\Pr[B]$
- 全概率公式算分母，贝叶斯定理算后验
- 独立：$\Pr[X=x\mid Y=y]=\Pr[X=x]$
:::
::: card 加密方案
- $\Pi=(\mathsf{Gen},\mathsf{Enc},\mathsf{Dec})$ + 有限 $\mathcal{M}$
- Gen 随机，Enc 可随机，Dec 确定
- Π<sub>shft2</sub>：后验 0.6 → 1，完全泄露
:::
::: card 完美保密（三种等价说法）
- 定义 3.1：任意分布下后验 = 先验
- 引理 3.3：$\Pr[C=c\mid M=m]$ 与 $m$ 无关
- 引理 3.5：任何敌手 PrivK<sup>eav</sup> 胜率 = 1/2
:::
::: card 证明套路
- 证“是”：条件概率 → 贝叶斯 + 全概率 → 密钥均匀约分 → 归一性
- 证“不是”：找一个分布或一个敌手（如维吉尼亚 aa/ab，胜率 3/4）
:::
::: card 一次一密
- $C=M\oplus K$，$K$ 均匀、与 $M$ 等长
- 完美保密（定理 4.1）
- 缺点：密钥长、只能用一次、只防唯密文
:::
::: card 局限与 Shannon 定理
- 完美保密 ⟹ $|\mathcal{K}|\ge|\mathcal{M}|$
- $|\mathcal{M}|=|\mathcal{K}|=|\mathcal{C}|$ 时：完美保密 ⟺ 密钥均匀 + 每对 $(m,c)$ 唯一密钥
:::
